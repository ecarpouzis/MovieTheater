MANGA SWEEP — the 214 shelves that do NOT tile, classified.
Produced 2026-09-08 after manga_sweep.py was run over all 591 non-null manga shelves
(377 wrote a decision file; these 214 did not). Read-only: nothing here was applied.

Two bugs were found and fixed IN the sweep before this list was trusted — see the notes at the foot.


A. THE RIPS NAME NO CHAPTER AT ALL — a real refusal.        194 shelves, 1,374 volumes
------------------------------------------------------------------------------------
Every one of these 1,374 archives opens, holds page images, and NOT ONE page name carries a
chapter token. They number pages inside the volume and nothing more:

    Bleach v1\Bleach v1-001.jpg
    Death Note Vol. 01 (2005) (Digital TPB) (DarkZone-Empire) 002.jpg
    Naruto v01 (2003) (Digital) (AnHeroGold-Empire)\001.jpg
    Case Closed v01 (2004) (Digital) (AnHeroGold-Empire)\...

Nothing can be read from them; a volume ordinal is not a chapter number (PLAN.md §4.2), so
they are refused. This is the dominant convention of the older Viz/Empire rips. They need a
different source (the volume's own contents page, or the publisher), not a better regex.

C. TRAPS THE TOOLS LEARNED (or still owe)
------------------------------------------------------------------------------------
FIXED in manga_sweep.py this run:
 1. `(c2c)` — the scanlation tag for "cover to cover" — was read as CHAPTER 2. Because
    RX_CHAP.search takes the first match in a filename, on a page named `... (c2c) ... c003 ...`
    the tag OUTRANKED the real chapter. Now a chapter number may not be followed by a letter
    (the `x<n>` extra marker excepted). Moved 5 shelves NO -> LADDER and corrected the low end
    of several others.
 2. RX_VOLNO held literal BACKSPACE bytes where `\b` was intended (PLAN.md §10.2 — a shell
    heredoc ate the escapes). It therefore matched NOTHING: volno() returned the 10,000
    sentinel for every volume and the volume-order guard the tool is built around was inert;
    the "volume order and chapter order disagree" test was really a FILENAME-order test, which
    SQLite's case-sensitive ORDER BY made wrong on its own (a lone lowercase "got" in one
    Slime filename sank v01 to the end of the shelf). With the guard live it flipped
    Onepunch-man out of a false LADDER (it had claimed c93-c104 across ten "volumes") and
    four shelves into real ones.
 3. A shelf name with an unrenderable character (a manga title with a star) raised
    UnicodeEncodeError at the END of a batch, after every archive had been read, and the state
    file was only written after the loop — so the whole batch's work was lost. stdout is now
    reconfigured and the state is checkpointed after EVERY shelf.

STILL OWED:
 4. A `c0` / `c000` page is front matter or a prologue, not chapter zero. It collapses a
    volume's low end and manufactures overlaps — the whole March Comes in Like a Lion tail
    (v08-v16) fails for this reason alone, and Hanaotoko and Hell's Paradise are damaged by it.
    Same family as the `c051x1` bonus-chapter rule already in the tool.
 5. `single volume` is accepted as a LADDER: 64 of the 377 files rest on ONE volume that
    states chapters, with no sibling to check it against. Six of those sit on shelves of more
    than three volumes (S557 Akame ga Kill!, S1349 As The Gods Will: The Second Series,
    S5805 Dragon Ball Super, S13015 No Longer Human, S19970 World is Dancing,
    S64737 Fushigi Yugi) — and in three of them the one ranged volume is a SPIN-OFF
    (Akame ga KILL! ZERO v09, Fushigi Yugi - Byakko Senki v01, No Longer Human Omnibus).
 6. 16 of the 377 ladder shelves carry more than one title stem. The ladder tiles only because
    the other work in the shelf was refused for naming no chapter; if it is ever ranged it will
    collide. The clear ones: S13245 One Piece (holds "One Piece - Ace's Story The Manga"
    v01 c1-2, v02 c3-4, while the main run's 84 held volumes below v085 name nothing),
    S67 20th Century Boys (The Perfect Edition), S2669 Black Cat (a Marvel
    "Black Cat by Jed MacKay Omnibus" filed in the manga shelf), S557, S7764 Golgo 13,
    S13015, S15318, S22969 Your Name., S64737.
    S2308 Battle Angel Alita Last Order is the benign case: Omnibus v01-v05 c1-c93 and singles
    v16-v19 c94-c124 genuinely continue one another.
 7. 41 manga collection items have a NULL SeriesId and are on no shelf, so the sweep never
    sees them.
