# Journey into Mystery v1 (2011) (S94776) - 4 collected editions, 14 issue files. Marvel.
#
# One run, one numbering: the shelf holds JOURNEY INTO MYSTERY 642-655 as loose files and four trades in
# a "Trades" subfolder. No conflation - every file carries the continuous Thor-legacy numbering.
#
# ONE trade states its contents and it is the only one written. Vol. 04 - The Manchester Gods carries the
# Marvel back-cover line "Collecting Journey Into Mystery #639-641 and The Mighty Thor Annual #1". The
# other three do not: their last pages are a Marvel house ad (Vol. 01, Vol. 02) or a scanlator joke page
# (Vol. 03), and there is no indicia page and no COLLECTING line anywhere I looked - p1, p2, the last
# three pages of each.
#
# What I DID read on the three refused books, recorded so the next reader starts ahead rather than
# repeating it:
#   * Vol. 01 (119pp) closes on a full-page card reading "JOURNEY INTO MYSTERY #626.1 - A Penny Dreadful
#     For Your Thoughts" at p-2, with only the house ad after it. A chapter cannot start two pages from
#     the end, so that card is a NEXT teaser and Vol. 01 ends at or before #626. Its first issue is not
#     stated anywhere in the book.
#   * Vol. 02 (142pp) opens on a reproduced cover whose Marvel corner box reads 626, and closes on the
#     same kind of card - "JOURNEY INTO MYSTERY #632 - Hot Dogs!" at p-2. Those two readings CONTRADICT
#     Vol. 01's closing card: one of them puts #626 in Vol. 02 and the other puts #626.1 there, and I
#     could not settle which without the point-issue suffix, which the corner box does not show. So no
#     range - a start that is wrong by one issue is exactly the shape that hides a file.
#   * Vol. 03 (120pp) opens on the SHATTERED HEROES-bannered cover that Vol. 02's closing card names as
#     #632, and its last text page ends "NEXT: EXILED #1!". Neither states an end.
# None of the three could over-claim onto a file we hold in any case: every loose issue on this shelf is
# #642 or higher, and the whole trade ladder ends at #641.
#
# Also: the Vol. 04 file is named with the prefix "05", not "04". Either a fifth book in the folder
# ordering was never ripped or the prefix is simply wrong; the book itself is titled Vol. 4.
