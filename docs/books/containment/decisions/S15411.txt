# Sgt. Fury (S15411) — 6 collected editions, 9 issue files (#1, #2, #37-#43).
#
# Two reprint LINES cover the same 1963 run — Marvel Masterworks (Vols. 01-04) and the Epic Collection
# (Vols. 01-02) — so the volume ordinals collide even though the ISSUE numbering does not. Every one of
# these books prints a contents page listing each issue it holds, so five of the six state their own
# range and the sixth follows from the one that does.
#
#   Masterworks Vol. 01  p003 lists "#1, May 1963" through "#13, December 1964"          -> 1-13
#   Masterworks Vol. 02  p003 lists "#14, January 1965" through "#23, October 1965" + Annual #1 -> 14-23
#   Masterworks Vol. 03  p003 lists "#24, November 1965" through "#32, July 1966" + Annual #2   -> 24-32
#   Masterworks Vol. 04  p003 lists "#33, August 1966" through "#43, June 1967"          -> 33-43
#   Epic Collection 02   p003 lists "SGT. FURY #20" through "SGT. FURY #36" + Annuals    -> 20-36
#   Epic Collection 01   the reproduced cover at p004 is issue #1; Vol. 02 starts at #20 -> 1-19
#
# The Masterworks ladder tiles #1-#43 with no gap and no overlap, and the Epic volumes sit across it on
# purpose — a second line reprinting the same issues, which is not a defect.
# ComicVine had the right range on the wrong book: it put Epic Vol. 01's #1-19 on Berlin Breakout.
