# What was read. These are scanlations, not a publisher edition: the volumes carry "The New Ranma Project"
# index page, and v20, v30 and v38 each print a contents list of exactly the same shape -
#     Ranma 1/2 [20]   PART. 1 The Shishihokodan .. 5 ... PART. 11 Waves of Rumors .. 165
#     Ranma 1/2 [30]   PART. 1 Ryoga's Spring .... 5 ... PART. 11 The Cursed Spatula .. 167
#     Ranma 1/2 [38]   PART. 1 Phoenix & Dragon .. 5 ... PART. 8 Akane's Smile, then Finale
# - three different volumes, three different sets of stories, all numbered PART 1 upward. v01's opening
# divider is likewise "PART 1: HERE'S RANMA". A range in this numbering would have thirty-eight volumes
# each claiming 1-11, which is the catastrophic overlap 2 warns about; over-claiming loses files, and
# refusing costs nothing here because the shelf holds no loose chapter files.
#
# v02 and v03 are from a different scanlation group again (mangareader.net watermarks) and v02's opening
# divider reads PART 9, so the shelf does not even hold ONE convention - some volumes continue a count and
# most restart it. That is a second, independent reason no single range can be written.
#
# What would settle it: the original Shonen Sunday chapter numbering (Ranma runs to about 407 chapters).
# Nothing inside these files states it.
