# Love and Rockets (S65085) - 16 collected editions, 24 issue files. EVERY range on this shelf is retracted.
#
# The shelf holds FOUR runs and none of them is the one the books collect:
#   Love & Rockets v2 (2001)        #1-5
#   Love & Rockets - New Stories    #1-8   (v3, 2008-2016, 102pp annuals)
#   Love and Rockets v4 (2016)      #1-4, #8, #14
#   The Love and Rockets Library    the 15 Fantagraphics reprint books (2007-2017)
# plus two Companion volumes, two FCBD giveaways and a cover gallery.
#
# The Library books reprint LOVE AND ROCKETS v1 (1982) #1-50, split into two interleaved story lines -
# "Locas" (Maggie & Hopey) and "Palomar & Luba". This library holds NOT ONE FILE of v1. So every span on
# this shelf is a range over issues that are not here, and every match it makes is a collision with a
# DIFFERENT run's numbering. That is exactly what was happening:
#
#   Penny Century (Locas #4)   was nesting Love & Rockets v2 #1-3 (2001) and Love and Rockets v4 #1-3 (2016)
#   Ofelia (Palomar & Luba #5) was nesting v2 #4-5, v4 #4 and v4 #8
#   The Girl From H.O.P.P.E.R.S. was nesting the 2023 v4 #14 and the 2016 FCBD sampler
#   Love and Rockets - The Covers, a 133pp COVER GALLERY, carried LOCG's #1-50 and was nesting nine files
#
# Thirteen files were assigned to a parent that does not contain them, and the containers' ranges reached
# over sixty more. Retracting all sixteen costs nothing: there is nothing on this shelf they could correctly
# hold. If v1 (1982) is ever added, these ranges have to be READ off the books - the sub-line numbering
# ("Locas #1", "Palomar & Luba #1") is a story-line volume count, not an issue range, and the two lines
# interleave, so Locas #1 and Palomar #1 both start at v1 #1.
#
# THE CAUSE OF THE FLAG DEFECT, which is worth carrying forward: twelve of these fifteen 224-297pp books
# were flagged IsCollection = 0, and the three that were not are exactly the three whose titles carry no
# '#N' - Amor Y Cohetes, Comics Dementia, Children of Palomar. The '#N' of the SUB-LINE ("Locas #1") was
# read as an issue number, and a file with an issue number is scored as an issue. So the title's own
# sub-title flipped the book out of being a collection, and while that flag stood the book could nest
# nothing. Fixed here by reading: IsCollection = 1, Format = TPB, and the sub-line number cleared on all
# twelve. Same for the Companion's '#30', which is the '30 Years' of its title.
#
# The shelf is also CONFLATED - v2, v3 and v4 each number from #1 - and is left that way deliberately.
# With every range retracted nothing can nest, so the conflation costs nothing today; splitting it is a
# separate operation and split_by_folder.py finds no run folder here (the four runs sit under one
# Fantagraphics title folder). Flagged so the next pass sees it rather than rediscovers it.
