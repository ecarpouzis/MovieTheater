# THE SHELF:
#   DC\_Supergirl\Supergirl v4 (1996)          issues 051-080, the Peter David run's back half
#   ...\Trades                                  five books, four of which belong here
#
# The four "Supergirl Book N" volumes are Son of Ultron rips of DC's Peter David collections and each
# states its contents on the copyright page at archive index 3, in the block under the credits:
#
#   Book One    "SHOWCASE '96 8, SUPERGIRL PLUS, SUPERGIRL 1-9, SUPERGIRL ANNUAL 1
#                (c) 1996, 1997 DC Comics"                                              ->  1-9
#   Book Two    "SUPERGIRL 10-20, SUPERGIRL ANNUAL 2 (c) 1997, 1998"                    -> 10-20
#   Book Three  "SUPERGIRL 21-31, SUPERGIRL 1,000,000 AND RESURRECTION MAN 16-17
#                (c) 1998, 1999"                                                        -> 21-31
#   Book Four   "SUPERGIRL 32-43, YOUNG JUSTICE 12-13 (c) 1999, 2000"                   -> 32-43
#
# The ladder tiles 1-43 with no gap; the copyright years step 1996 -> 2000 in lockstep with it, which is
# a second confirmation that all four are the 1996 run. Issues #44-50 are in no book here and are not
# held; the thirty files on this shelf are #51-80 and sit past the end of every range.
#
# THE FIFTH BOOK IS NOT THIS RUN. "Supergirl Book 05 - The Hunt for Reactron" reads, in its own indicia:
# "SUPERGIRL VOL. 5: THE HUNT FOR REACTRON ... Originally published in single magazine form in
# SUPERGIRL 44-50, SUPERGIRL SECRET FILES 2009 1, SUPERGIRL ANNUAL 1, ACTION COMICS 881, 882.
# Copyright (c) 2009..." — Action Comics #881-882 and Secret Files 2009 are the New Krypton era, so the
# "44-50" in that line is the 2005 Supergirl, not the 1996 one, whose #44-50 shipped in 2000-2001.
#
# This is the trap this shelf sets: 44-50 is exactly the hole Books One to Four leave, so a range taken
# from that indicia would slot into the ladder and look right. It would be a claim about a different
# series in a different decade. It is refused, and the file is flagged as filed on the wrong shelf.
