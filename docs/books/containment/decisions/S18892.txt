#          lost love 111 / 4th delivery: september rain 157 / disjecta membra: glossary and notes 203

#          as time goes by 183 / afterword from the author 213
#     v06  1st delivery: a letter for you 5 / ... / 6th delivery: too long a spring 185
#
# `1st delivery` in v06 is not chapter 1 of the series; it is the first chapter of v06. Six volumes were
# read (v01-v07) and every one of them opens at `1st delivery`, so this is the edition's convention and
# not one volume's quirk. A range taken from these numbers would give every volume on the shelf a range
# starting at 1 — fourteen books all claiming the same chapters, which is exactly the shape that loses
# files when a de-duplication reads it.
#
# The only other number the books carry is the volume ordinal in the file name, and §6.2 is explicit
# that a `#N-N` equal to the volume ordinal is an artefact, not a range. So there is no usable
# coordinate here and the shelf is refused.
