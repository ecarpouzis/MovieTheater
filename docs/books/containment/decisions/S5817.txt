# Dragon Head (S5817) — the complete ten-volume Mochizuki run, in four different scanlations. No loose
# issues on the shelf.
#
# The rips disagree about how to name a page, so the archive's own tokens could not be trusted on their
# own — v07's pages read `Dragon Head Vol07 Ch01`..`Ch07`, which is a WITHIN-VOLUME ORDINAL, while v08's
# root folder reads `Dragon_Head_v08_c72-76_[Blackout+Null+I-M]`, which is the running chapter number.
# Taken at face value the two contradict each other.
#
# What settles the whole shelf is that Dragon Head PRINTS A CONTENTS PAGE in every volume, and eight of
# the ten rips kept it:
#
#     DRAGON HEAD — 1. CHAPTER: THE LAST CLASSTRIP 10 / ... / 11. CHAPTER: AT HOME 202      (v01)
#     CONTENT — Chapter 65 : The escape / ... / Chapter 71 : The mall                       (v07)
#     CONTENTS — CHAPTER 84 : The letter 011 / ... / CHAPTER 89 : The horror of ending      (v10)
#
# so v07's `Ch01`-`Ch07` is proven to be chapters 65-71, and every other volume states its own numbers.
# The contents page sits at a different archive index in each rip (v01 p47, v02 p3, v03 p2, v05 p1,
# v06 p2, v07 p2, v08 p1, v09 p2, v10 p2) because the rips carry different amounts of front matter; it
# was read in each book, and the index only says where to look.
#
# v04 IS THE ONE VOLUME WITHOUT A CONTENTS PAGE — its rip is missing its first five pages entirely (the
# untokened set starts at `Dragon Head v04 006.jpg`). It was settled by hunting its printed chapter
# dividers instead, which Dragon Head draws into the art at the foot of a chapter's first page:
#
#     page 026  `chapter 38 — The ghost town`          page 039  `Chapter 39 : The group`
#
# and its remaining pages carry the tokens `Vol04 Ch39`..`Ch47`. With v03 ending at chapter 36 and this
# book's second chapter printed as 38, its opening pages are chapter 37 — so v04 is 37-47.
#
# The ladder tiles exactly, chapter 1 to chapter 89, with no gap, no overlap and no inversion:
#   v01 1-11, v02 12-23, v03 24-36, v04 37-47, v05 48-57, v06 58-64, v07 65-71, v08 72-76,
#   v09 77-83, v10 84-89 — which is the whole run.
