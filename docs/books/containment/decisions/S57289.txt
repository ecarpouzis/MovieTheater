#                                          \... Part 02 - Battle Tendency (1987)
#                                          \... Part 03 - Stardust Crusaders (1989)
#                                          \... Part 04 - Diamond Is Unbreakable (1992)
#                                          \... Part 05 - Golden Wind (1996)
#                                          \... Part 06 - Stone Ocean (2000)\Chapters + \Omnibus Editions
#
# Each Part is its own serialisation. Every one restarts its VOLUME numbering at v01, and the two rips
# that name chapters restart those at c1 as well:
#
#     Part 5 Golden Wind v01  c1-c15   (LuCaZ, chapter named on every page, `(v01)` beside it)
#     Part 6 Stone Ocean v01  c1-c17   (Omnibus Edition, same rip convention, also `(v01)`)
#
# so Golden Wind v01 and Stone Ocean v01 both claim "chapters 1-15/17" of different manga. A range
# written in this Series would put them in one number space and each would nest the other's files. That
# is exactly the cross-run collision PLAN.md §4.4 and §14.1-14.2 describe, and the fix is above the
# range: the shelf has to be split per Part first.
#
# REFUSED, all 34. The refusal is not for want of evidence — Parts 5 and 6 state their chapters
# precisely, and once this shelf is split those eighteen books can be ranged in one pass:
#
#     Part 5  v01 c1-15, v02 c16-33, v03 c34-51, v04 c52-69, v05 c70-87, v06 c88-105, v07 c106-123,
#             v08 c124-140, v09 c141-155
#     Part 6  v01 c1-17, v02 c18-36, v03 c37-54
#
# Parts 2, 3 and 4 put no chapter token on any page and would still need their books opened.
#
# A DATA DEFECT UNDERNEATH: `ComicDetail.IssueNo` on these books is the PART number — every Stardust
# Crusaders volume is issue 3, every Diamond Is Unbreakable volume is issue 4, Golden Wind 5, Battle
# Tendency 2. Ten different books share each of those numbers, so the shelf cannot order or attach
# anything by issue number either.
