# One run and nothing else. Infinite Crisis is a seven-issue maxiseries and the FILENAMES say so:
# "Infinite_Crisis_03__of_07__". All seven are here twice, once in the post-Crisis events tree and once
# in the Green Lantern Corps chronology tree, plus two 2pp cover scans of #6. There is no second
# numbering on this shelf for a range to collide with, which is the condition that made half the
# refusals in this pass necessary.

# The two collected editions are the same 242pp book ripped twice - both "Infinite Crisis (2006)
# (Digital) (Zone-Empire).cbr", both 462.8MB - filed under two different event folders. Seven issues of
# 30-36 pages is about 232; the book is 242. LOCG's #1-7 agrees with the run length the files themselves
# state. Stored at 0.88 rather than higher because I did not reach the indicia page in either rip: the
# evidence is the title (no volume marker, no part), the arithmetic, and the "(of 07)" the ripper wrote.

#   read as #11 it sat outside every range the run could have.
#   19333, the trade, was #1, taken from the "01 " sort prefix of its own filename.
