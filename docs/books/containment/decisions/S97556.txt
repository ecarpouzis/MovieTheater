# Heroes for Hire v2 (2006) (S97556) - 2 collected editions, 15 issue files. Marvel.
#
# The shelf holds the WHOLE 2006 run as loose files, #1 to #15, and two of its three trades. That is the
# shape where a wrong range costs files, so both were read off the book and neither was inferred.
#
# Neither trade carries a back-cover COLLECTING line - the last page of each is the end of the story -
# but both state themselves another way, and both ways are §14.8 evidence:
#
#   * Vol. 02 - Ahead Of The Curve has PER-ISSUE CREDITS on its title page (p2), attributed three times
#     over: writers by issue, pencilers by issue, cover artists by issue, and every one of them spans
#     #6 to #10. Its first reproduced cover (p3) is captioned #6.
#   * Vol. 03 - World War Hulk has a captioned CHAPTER DIVIDER before each chapter. I read them: p3 is
#     captioned 11, p49 is captioned 13 and p95 is captioned 15, with the same purple divider band at
#     p26 and p72 for the two between. Five chapters over 121pp, which is the same page-per-issue rate
#     as Vol. 02 (117pp for five).
#
# Vol. 01 (#1-5) is not on this shelf, so #1-5 are loose and uncollected here. That is a gap in the
# ladder, not a gap in the reading.
