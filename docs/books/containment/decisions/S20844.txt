# THE TRAP THIS SHELF SETS. Every archive names a chapter on every page, and every one of them runs
# `c001` .. `c017`/`c019`/`c022`. Taken at face value all sixteen omnibuses collect "chapters 1-22" —
# sixteen identical ranges over the same numbers. That is why the manga sweep refused the shelf, and it
# was right to: the chapter number in this rip RESTARTS with every Japanese volume, so it is a
# within-volume ordinal, not a coordinate the shelf can be ranged in.
#
# What the same page names DO state, unambiguously, is the Japanese VOLUME:
#
#     Urusei Yatsura - c001 (v03) - p000 [Cover] [dig] [VIZ Media] [LuCaZ] {r2}.jpg
#
# Each omnibus carries exactly two volume tokens, ~190 pages under each, and they run straight through
# the shelf with no gap and no overlap:

#   Omnibus v02 (v03)+(v04)   v06 (v11)+(v12)   v10 (v19)+(v20)   v14 (v27)+(v28)

#   Omnibus v04 (v07)+(v08)   v08 (v15)+(v16)   v12 (v23)+(v24)   v16 (v31)+(v32)

# So these are VOLUME-coordinate ranges (PLAN.md §4.2: an omnibus collecting volumes X-Y is X,Y), and
# the title on the tin agrees — Viz sells this line as a 2-in-1 edition, and every archive holds exactly
# two volumes' worth of pages. Thirty-two volumes over sixteen books, which is the whole run.
