# Heavy Metal (S8533) — the leftovers of the magazine: 21 collected-flagged files spread over the
# 1989, 1990, 1992, 1997, 1999, 2003, 2007, 2008 and 2009 back-issue folders, the Annuals and
# Specials folder and Related_Publications, alongside 64 loose issues of the same magazine.
#
# Nineteen of the twenty-one are ordinary issues — `Heavy Metal 2007 Vol.31 No.03 (July)`,
# `Heavy Metal v27 004 (2003)` — 111 to 133 pages each, flagged IsCollection=1 because of the volume
# token in the name (§14.6). A magazine issue is a base unit and collects nothing numbered.
#
# One is different and is refused for a different reason: `Heavy Metal Book 1993 Bad Blood - The
# Vampire Collection` really is an anthology, but what it gathers are stories picked out of many
# issues over many years. That is containment with no coordinate — there is no contiguous run of
# numbered units for a range to name.
#
# The same shelf mixes issues numbered three different ways — `Vol.13 No.05`, `v27 001`, `1992-11
# (V17 04)` — which is worth knowing before anyone tries to build a ladder here.
