# Supergirl v5 (2005) (S94709) - 13 collected editions, 11 issue files. DC.
#
# ONE run (Supergirl 2005, issues #0-67) collected TWICE over, and both ladders sit on this shelf:
#   * the nine original trades, 2006-2011, in "Supergirl v5 (2005)";
#   * four 2015-2018 re-collections in "Supergirl v5 (2005)\New TPB Editions".
# They overlap by design. An issue may sit in two books, so the two ladders are not a conflation and no
# split is needed - the run marker and the issue numbering are the same throughout.
#
# Eleven of the thirteen were read off the book. The two ladders use DIFFERENT evidence shapes and both
# are recorded as such:
#   * the original trades print "Originally published in single magazine form in ..." on the copyright
#     page (p2 for Vol. 02 and Vol. 03, p3 for Vol. 04 through Vol. 09);
#   * the 2015-2018 re-collections print a TABLE OF CONTENTS on p3 naming the source issue of every
#     chapter ("TESSERACT / SUPERGIRL #23"). I read the first and the last entry of each.
#
# THE ONE THAT COSTS FILES. Vol. 07 - Friends and Fugitives collects SUPERGIRL 43, 45-47 - it does NOT
# contain #44, and #44 is a file we hold (item 70454). Stored as the hull 43-47 with the indicia
# quotation intact so SpanEvidence.ExcludedIssues can read the hole; without the quotation this row
# would call a real file redundant.
#
# Two refusals, and both are honest silence rather than a guess:
#   * Vol. 01 - Power carries no copyright block anywhere in p0-p5 or the last two pages. It is written
#     as the complement below Vol. 02 (which begins at #6) at a lower confidence.
#   * Vol. 06 - Who is Superwoman? is REFUSED. Its copyright block is not on p1-p5 nor the last three
#     pages; all I could read is a single closing gallery page captioned SUPERGIRL 34 VARIANT COVER. It
#     sits in the gap between Vol. 05 (ends #33) and Vol. 07 (begins #43), but 167pp cannot hold the
#     nine issues #34-42 - every other trade on this shelf runs about 22pp per issue - so the complement
#     is NOT determined and a range would be invention.
#
# A defect worth naming: the original ladder never collected #20-22 (Vol. 03 ends at #19, Vol. 04 begins
# at #23). That is a real publishing gap, not a missed reading - the 2016 re-collection Vol. 02 covers
# #11-22 precisely because the original ladder skipped them.
