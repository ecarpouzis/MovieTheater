#     Contents — A Note from the Author iv / Honorifics Explained v / Nodame's Kingdom 2 /

#     Nodame Cantabile — Contents — Lesson 101 ... 5 / ... / Lesson 106 ... 143              (v18)

# in each book; the index only says where to look.

# TWO THINGS ON THIS SHELF THAT ARE NOT THE MAIN RUN:

#     `AKT:1 ... 5 / AKT:2 ... 37 / AKT:3 ... 67 / AKT:4 ... 98 / AKT:5 ... 133 / BONUS STAGE ... 165`,
#     and v25's chapter openers continue `AKT:6`. That is the Opera-hen sequel's own numbering, starting
