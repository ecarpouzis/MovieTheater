# Wolverine Weapon X (S21839) — 3 collected editions, 16 issue files (#1-#16, no gap, no repeat).
#
# The shelf proves itself. The X-Men Complete Chronology filed this run one arc to a folder and named the
# folders after the arcs, and each trade carries the same arc name as its subtitle:
#
#   "0814 The Adamantium Men"   holds #1-#5    -> Vol. 01 - Adamantium Men        145pp / 5 = 29pp
#   "0841 Insane In The Brain"  holds #6-#10   -> Vol. 02 - Insane in the Brain   127pp / 5 = 25pp
#   "0861 Tomorrow Dies Today"  holds #11-#16  -> Vol. 03 - Tomorrow Dies Today   176pp / 6 = 29pp
#
# Sixteen files, sixteen issues, one numbering, and the three ranges tile it exactly. Every issue is
# 25-26pp, so each trade is its arc's pages plus 17-21pp of matter — except Vol. 02, which is 2pp under
# the raw sum, the ads a trade drops.
# The claims here are all wrong and two of them are live: LOCG matched Vol. 01 and Vol. 02 to the single
# comics "Wolverine: Weapon X #1" and "#2" (hence #1-2 and #3-3), and gave Vol. 03 the whole run.
