# Conventions of this corpus, for the ledger:
#  · A "COL <Title> vNN (<year>) (Digital) (<group>).cbz" at 150-250pp is one tankobon; 300-600pp with
#    "(Omnibus Edition)" or "3-in-1" is a collected edition and is a DIFFERENT record from the volume line.
#  · Loose "Title NNN (year)" files at 15-60pp beside the volumes are the magazine CHAPTERS of the same comic,
#    not a second run — residue that costs nothing.
#  · Waifu2x Upscale / [ScanlationGroup] filenames are fan scanlations of the Japanese volumes; the comic is
#    still the comic, but the edition our files are is neither provider's, so those cap at 0.9.
#  · GCD is thin on modern English manga: 22 shelves here have a CV English volume and NO English GCD row.
#    Per Eric's Europe-Comics ruling I link the same work's row in another language (Japanese original first,
#    else the European edition) at 0.9 naming the language, and write gcd=- + provider-missing only where GCD
#    has no row for the work at all.
#  · A publisher change mid-line splits the GCD leg in two (Vertical -> Kodansha USA on Ajin, Blood on the
#    Tracks, CITY, Miss Nagatoro): take the majority row and name the split, 0.9.
