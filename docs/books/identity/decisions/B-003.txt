# B-003 — 150 tier-B shelves: Archie (71), Aspen (1), Avatar Press (14), Behemoth (9), Berger Books (17),
# Black Mask (2), Bongo (10), Boom! Studios (26).
#
# ARCHIE is the publisher this batch is really about, and it has a convention I have not seen named in
# the ledger: Archie files its annual holiday one-shots as a NEW series every single year. Both
# providers do the same — CV mints "Archie Christmas Spectacular" 2019, 2020, 2021, 2023, 2024, 2025 as
# six separate volumes and GCD mints 135692 / 153788 / 167909 / 179173 / 193767 / 207594 as six separate
# series — so a shelf holding four years of a holiday special is four comics with four records and NO
# record that spans them. That is why S1228 and S1246 are R + split-needed rather than a 0.7 guess:
# there is nothing to link them to. Where a shelf holds ONE year, the year in the FILENAME is the only
# thing that picks the record (the ComicInfo Series' "(2023)" suffix is the publisher's own label and
# disagrees with the file on S1230).
#
# BOOM! STUDIOS behaved exactly like AWA/Ablaze in B-002: run + count-1 trade a year later, in both
# providers, and the stored CV link is the trade on six of the eleven Adventure Time mini shelves
# (Candy Capers, Marceline Gone Adrift, Ice King, Beginning of the End, Alienated, Fionna & Cake).
# The Adventure Time "Minis" folder is one numbered subfolder per mini and each is genuinely its own
# six-issue series — the numbering in the folder name is a reading order, not an issue ladder.
#
# THE DUMP'S SPELLING, AGAIN: as in B-001, re-probing with the RECORD's title rather than the parsed
# key found the missing GCD leg on 11 shelves — 118833 Best of Archie Americana, 184500 Bite Sized
# Archie, 196895 Betty the Final Girl, 201499 Camp Pickens, 208190 Sabrina Holiday Special, 156396
# Archie Meets the B-52s, 236352 Love Showdown 30th Anniversary, 63772 Ralph Wiggum, 124162 Fionna and
# Cake FCBD, 21799 "Garth Ennis Chronicles of Wormwood", 13247 Archie's Pal Jughead Comics.
#
# ONE FINDING WORTH THE LEDGER: shelf S97993 is named "Jughead v2 (1987)" and its per-file link is CV
# 11650 (Archie 1987, 45) — but its ladder is 150-211. Those issues are not in a 45-issue series at
# all; they are "Archie's Pal Jughead Comics" (CV 20115 / GCD 13247, Archie 1993-2012, 169), the
# continuation that kept the legacy numbering. A ladder that runs far past a linked volume's COUNT is
# the cheapest possible test for this, and it caught the one real mis-identification on the batch.
#
