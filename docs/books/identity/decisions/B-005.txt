#     Witches / Dragons / Giants / Fairies / Sirens / Ghosts / Tricksters / Shapeshifters. Probing with the
#     "Jim Henson's" prefix finds only the trade; drop the prefix and the run appears.
# (b) **BOOM's Power Rangers Unlimited / Saban's specials are one count-1 record per one-shot in both
#     providers** — clean 0.95 pairs, twelve of them here, and the only per-file GCD misses are round2-folder.

#     "Ruinworld" (143014), "Mighty Morphin Power Rangers / Teenage Mutant Ninja Turtles II Black and White
#     Edition" (207338) — four second legs won purely by re-spelling the probe.
