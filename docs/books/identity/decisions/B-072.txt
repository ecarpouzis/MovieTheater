# B-072 — 150 shelves, and 148 of them are ONE FILE: the `_Marvel Major Event Chronology (digital)` tree is a
# reading order over Marvel's events, one folder per tie-in holding that tie-in's collected edition. So the
# batch is a single shape repeated 150 times, and the ruling that decides it is "the RUN wins whenever a
# numbered run exists": where both providers hold a numbered mini behind the trade (Fear Itself: Youth in
# Revolt 6, Secret Invasion: Front Line 5, every Secret Wars Warzones! mini 4-5), the S line is that run and
# the count-1 collected record goes on the book's I line; where the book collects arcs of an ONGOING or
# several different series and both providers mint only the count-1 record (Civil War Companion, Secret
# Invasion: War Machine, Avengers: Standoff), that record IS the comic. The stored link is the count-1 trade
# on 60 of these shelves — the count-1-trade-as-stored-link artefact at full strength inside one folder.
# GCD's page counts did the per-book work: `gcd_issue` matched our rips within 3-20pp on every trade here.
# Two-thirds of the GCD collected records come in TWIN rows (78148/78149, 211378/219185, 63446/71177 ...),
# which is what caps so many lines at 0.9.
