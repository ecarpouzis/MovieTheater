# A-004 — 96 shelves: the tail of American Mythology's Zorro line, America's Best Comics, the whole
# Archie block (one-shots, team-ups, Jughead, the Riverdale trades), Aspen, a long Avatar Press run,
# Behemoth, Berger Books and Black Mask.
#
# Folder conventions learned here:
#   * Archie files its licence lines in _prefixed bucket folders — `_Archie One-shots`, `_Archie Team-ups`,
#     `_Archie Holiday Books`, `_Betty & Veronica`, `_Jughead` — so a shelf's folder says nothing about
#     which run it is. That is exactly the condition in which GCD's `round2-folder` method fails: three
#     Archie shelves in this batch were handed a neighbour's series (Archie Meets Ramones -> "Archie vs
#     Sharknado", Archie vs. The World -> "Archie: The Decision"), and in both cases the dump held the
#     right record under the file's own title.
#   * Avatar Press files by title with no year folder, and ships cover-only and variant-pack rips beside
#     the issues (`\covers`, "Variant Covers Pack", "3 covers only", 3-4pp). Those inflate the file count
#     and make the numbers collide without making the shelf two runs.
#   * Archie's trade shelves are the hard reading of this batch. CV usually carries BOTH the floppy run
#     and a one-issue TPB record; GCD carries the run and a `collected edition` series. My rule, applied
#     line by line: take the record the two legs AGREE on — where both carry a collected edition whose
#     issue count equals the number of volumes we hold (Riverdale, Road to Riverdale, Incognegro:
#     Renaissance) that is the identity; where the collected records disagree in count, the agreement is
#     at the RUN (Vampironica, Vampironica: New Blood, The Archies, Jughead: The Hunger, Josie), and there
#     the judged spans from the containment pass are what proves it — #1-3 + #4-7 = the run's 7 issues,
#     #1-3 + #4-8 + #9-13 = its 13, #1-5 + #6-9 = its 9.
#
