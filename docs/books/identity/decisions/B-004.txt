# Archaia). The house shape here is one file per shelf: a 100-200pp digital trade or OGN of a 4-8 issue
# Boom mini. That produces the SAME three-record trap the ledger records for Image and Boom trade shelves —
# the RUN (CV volume with the real count + a GCD row with the same count and years), and a same-title
# count-1 record one year later in BOTH providers which is the TRADE. The stored CV link is the trade
# record on 13 shelves in this batch (wrong-cv-link); where it is the run, the trade's own count-1 GCD row
# is what the book's `I` line carries. Second legs: the GCD dump reaches most of these under the exact
# title, but a re-probe with another spelling won the leg on six shelves the packet had given up on
# (Drew and Jot -> "Drew and Jot: Dueling Doodles" 154271; Hexed -> "Hexed Ongoing" 82276; Storyteller
# Giants/Fairies -> the "The Storyteller: <X>" run rows, without the "Jim Henson's" prefix; Ghosted in L.A.
# -> CV 120110 the 12-issue run; Ben 10 -> five separate one-shot records). Archaia's small 2011-2012 OGN
# line (Black Charity, Black Fire, Bleedout, An Elegy for Amelia Johnson, Genetiks, I'm Not a Plastic Bag,
# Iron) is indexed in GCD in the 216900s as a block — those all pair cleanly.
# Conventions this batch adds: (a) BOOM's licensed-kids folders (Ben 10, Ice Age, Garfield, BOOM! Box Mix
# Tape) file a NEW record per book/year in both providers, so a folder of them is N comics with no spanning
# record — R + split-needed, the same shape the ledger records for Archie holiday one-shots; (b) BOOM's
# Buffy/Angel Library and Legacy Editions are reprint lines over Dark Horse runs — the Legacy line is one
# 6-volume record both providers hold, the Season 11 Library Editions sit on the Dark Horse runs their
# judged ranges name; (c) round2-folder handed the BRZRKR Pen & Ink one-shot's series to two SIBLING
# Pen & Ink one-shots (Fallen Empire, Poetry of Madness) — wrong both times, and the dump names each.
