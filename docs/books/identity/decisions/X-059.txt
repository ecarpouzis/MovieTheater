# shapes: a "<Line> Epic Collection: <Subtitle>" single-book shelf's own S already carries the book's CV issue
# (from "cv issues") and the matching GCD line issue is found by subtitle text in the shelf's "gcd issues" pool —
# the round2-folder flag on these picks is right whenever the subtitle matches, confirmed repeatedly. A pooled
# multi-book shelf (Deadpool World's Greatest, Immortal Hulk, Uncanny Inhumans, Hawkeye v4/Kate Bishop, Rocket
# Raccoon and Groot, All-New Invaders/Inhumans) needs each book's OWN per-title CV volume looked up separately —
# CV mints one volume per trade far more often than the packet's per-file picks show, and the per-file CV pick is
# very often the underlying ONGOING run's issue by ordinal, not the trade's own record (reject, cv=-, and look up
# the real one). "C OWED" collected-line shelves (Captain Marvel v10, Deadpool v3->World's Greatest, Rocket
# Raccoon and Groot, Uncanny Inhumans, Immortal Hulk) pair a shelf S line that names BOTH a floppy run (cv=) and a
# TPB line (gcd=) together — the C line must find the FLOPPY's own GCD series (a plain "was ongoing series" row of
# matching count/years), never the TPB line's own id restated.
