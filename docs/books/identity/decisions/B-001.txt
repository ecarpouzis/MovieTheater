# B-001 — 150 tier-B shelves: 2000AD/Rebellion (98), AC Comics (50), AWA Upshot (2).
#
# TIER B means one recorded leg, so the work on this batch was FINDING the second one. The packet's
# "GCD dump:" line is a lookup on the shelf's PARSED KEY, and on Rebellion shelves that key is a
# mangled filename ("Judge Dredd - The Cursed Earth" for a book actually called "Judge Dredd: The
# Cursed Earth Uncensored"). Re-probing the same dump with the RECORD's spelling — the title the CV
# candidate list already showed me — found the missing GCD series on 14 shelves the packet reported
# as having none: 224303 Complete Bad Company, 190085 Cursed Earth Uncensored, 112605 A.B.C. Warriors
# Mek Files, 193412 Solo Missions, 190558 Hondo City Justice, 191950 Ampney Crucis, 119474 Sci-Fi
# Thrillers, 122128 Brothers of the Blood, 130313 Anderson Deep End, 160044 Smash! Special, 51959
# Complete D.R. & Quinch, 67428 Life and Death of Johnny Alpha, 23992 Untold Origin, 23706 Rio Rita,
# 25152 Femforce Spotlight, 113002 Misty. That is the single biggest finding of the batch: on a tier-B
# Rebellion shelf, "the dump names no other series" usually means the KEY was wrong, not the dump.
#
# Rebellion's own conventions, as they read here: one 100-350pp collected book per file, "COL <Title>
# vNN - <Subtitle> (YYYY) (digital) (<ripper>).cbr", and BOTH providers mint one record per BOOK for
# the Judge Dredd TPB line — so a shelf of one book with CV count 1 and a GCD count-1 row of the same
# year is not a "matches our holdings" trap, it is simply how a one-shot graphic novel is indexed.
# Where CV mints a volume per book but GCD keeps one series for the line (Johnny Alpha v09+v10), the
# two shelves share the GCD id and take F merge-with, the Epic-Collection shape from the ledger.
#
# AC Comics behaved exactly as the ledger says: one folder per title, CV and GCD each holding one
# record with the same publisher, year and count, and a ratio > 1 that is always duplicate printings
# (Big 'Uns #1 five times, Haunted Horseman twice). 41 of the 50 AC shelves are 0.95 on that pair.
#
# WEB: 0 fetches; the three hosts 403 per the brief. Two shelves needed an outside answer and carry
# F needs-web (S48, S6699) and are at 0.7 / R rather than guessed.
#
# I LINES: 82 written. Almost every shelf here is a single collected book, so the shelf's identity and
# the book's are the same question. Our data holds no CvIssue id for any of these volumes and no GCD
# ISSUE id, so every I line uses the permitted gcd=s<series> form (plus the two scanned ISBNs). Where
# neither provider names a series for the book, no I line was written and the S/R clause says so.
