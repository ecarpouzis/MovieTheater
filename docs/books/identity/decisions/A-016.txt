# A-016 — 121 shelves: the tail of IDW Hasbro (Transformers, the five _First Strike one-shots, the TMNT
# collected lines) and then IDW proper from 3 Devils to Star Trek vs. Transformers. Almost the whole batch is
# one publisher, and IDW's house shape is the cleanest kind of shelf there is: a 3-6 issue mini whose files
# carry "(of NN)", a CV volume and a GCD series that agree on IDW, the year and the count, and a complete
# ladder. Roughly 75 of the 121 lines are that.
# The one systematic trap is the same one A-014 found at Dynamite, and IDW runs it even harder: for nearly
# every mini there is a SECOND same-title IDW record a year later with count 1 — the trade — and on a
# trade-only shelf the stored CV link is that record about half the time. Fourteen shelves here needed
# F wrong-cv-link for exactly that shape, and the tell is always the same: count 1 (or a count equal to the
# BOOKS we hold) against a 4-25 issue GCD series of the same name one year earlier.
# I-line convention as before: a book gets an I line only when its own record differs from what the S line
# carries; no item-level ComicVine issue ids appear in this packet, so every I line is gcd=s<series>.
# What surprised me: IDW's LIBRARY/ARCHIVE lines (Godzilla, D&D, Star Trek Library Collection, Star Trek
# Classics, Gold Key Archives, Stardate Collection, TMNT Adventures/Classics) all behave like the reprint
# library rule — a collected line over material with no single run record — so they are 0.9 plus an N naming
# what they reprint, not a run link.
