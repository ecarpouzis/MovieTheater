# `Heavy Metal\Heavy Metal Magazine (1977)` - its `Related_Publications` tail (11 shelves), its
# `_Back Issues\YYYY` per-issue shelves (81) and its `_Back Issues\YYYY\special` shelves (28).
# This batch is not 120 comics. It is TWO magazines plus eleven albums, and the tier is an artefact: every
# shelf here is ONE FILE cut out of a back-issue tree by the ripper's `Heavy_Metal-YYYY-MM-VVxNN-Month`
# filename, which the parser read as a title and as a ladder of the MONTH (hence "ladder 3" on every March).
#
# (1) The `_Back Issues\YYYY` shelves are ONE ISSUE EACH of Heavy Metal Magazine - CV 19498 / GCD 110631,
#     the shelf B-034 read as S8533 (and into which it already merged twelve `v01 (1977)` folder shelves,
#     S94623-94634). All 81 take those ids + `F merge-with=8533`. The filename's `VVxNN` is the indicia's
#     Volume x Number and ComicVine's issue NAME is literally "Vol. NN, No. NN", so the cover month pins
#     each file to exactly one CV issue and one GCD issue: 81 files, 81 exact per-book pairs.
# (2) The `special` shelves are a DIFFERENT magazine: CV 35025 "Heavy Metal Special" 1989 Heavy Metal, 53
#     issues, and GCD 77284 "Heavy Metal Special Editions" 1981-2008, 50 issues - the row S8533's own `N`
#     note already named for "the specials filed alongside". BOTH legs index it, and both index it by the
#     special's own SUBTITLE: GCD in `gcd_issue.title`, ComicVine in the issue NAME, which from 1999 on even
#     carries the "Vol. NN, No. NN" our filenames' `SE-VVxNN` asserts. 28 of 28 matched on subtitle, number
#     and cover month. Probing the specials' own titles finds NOTHING (24 tried) - the volume is called
#     "Heavy Metal Special", and it surfaced only because the packet for two 2008 shelves in D-011 happened
#     to list it as a candidate. The count difference is the ends: GCD holds the 1981-1986 specials that CV
#     mints as separate volumes (35034, 33975), CV holds the 2009-2011 ones GCD folded into 110631.
# (3) `Related_Publications` is the album/art-book tail D-009 began. Its lesson is this batch's systemic
#     finding: an EXACT `lookup.py "Lorna"` returns only foreign editions, while `--contains "Lorna"`
#     returns SIX English Heavy Metal albums both catalogs hold (Mouse Club CV 31447/GCD 51542, and Her
#     Robot 24039/21138, Leviathan 37426/51538, The Ark, The Eye of Dart-An-Gor, The Black Castle). D-009
#     wrote `R` + provider-missing on two of those six (S8696, S8697) - both are wrong; see the N lines.
# The cheapest instrument on this folder was not a title probe at all but
# `SELECT * FROM gcd_series WHERE publisher_id=384`: Heavy Metal's entire GCD output is 90 rows, and
# reading it resolved Margot, Keepers of the Maser and both Lorna albums after every title probe had failed.
