# B-060 — the Marvel tail: Thanos leftovers, Thor (and Journey into Mystery, Beta Ray Bill, Angela),
# Thunderstrike, Thunderbolts, the whole Ultimate line, Venom, Vision, What If?, White Widow and the start of
# Wolverine. 150 shelves; ~120 hold one book. The same two folder shapes decide it as in B-059:
#   * a `<Title> [vN] (<year>)` per-title folder holding only a collected edition is the RUN's folder — the run
#     takes the S line and the trade an I line. Twenty-one `wrong-cv-link` flags here are that one artefact:
#     the stored link is the count-1 trade record minted beside the mini a year later.
#   * a loose file in a bucket (`_Trades, One-shots and Minis`, `_Trades, Minis and One-shots`, `Trades`,
#     `_Ultimate One Shots`, `_Omnibus Editions`, `What If 2005`…) names no run, so the BOOK's own count-1
#     record — which both providers mint for almost every Marvel book of this era — is the identity.
# Epic Collection / Complete Collection LINES take the line at 0.9 with the run named (the lead's 2026-09-10
# ruling): ComicVine mints a volume per BOOK (22 Thor, 11 Wolverine) while GCD keeps one line row (74601,
# 80971), so `cv=-` on those S lines is a real absence, not a withheld id, and each book's CV issue carries
# the I line instead. Its "Volume N" labels matched our filenames volume-for-volume on all 18 such books.
# Surprises: the packet's probe missed FOUR Thunderbolts one-shots that GCD does hold under the CV spelling
# (25817, 29885, 30736 and 198243), and "Venom: Lethal Protector II" is a separate 5-issue run in both legs
# that the stored link had collapsed into the 2022 Lethal Protector.
