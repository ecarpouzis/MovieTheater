# D-014 — tier D, 120 shelves, almost all of it the `Marvel\` tree. Four shapes carry the batch:
# (1) A SINGLE BOOK (a trade, an omnibus, a one-shot) sitting alone in a run's `<Title> vN (<year>)` folder.
#     Where BOTH providers carry a multi-volume collected LINE coextensive with the shelf, the LINE takes the
#     S at 0.9 with an `N` naming the run (the S16653 ruling); where the shelf is one trade of a numbered run,
#     the RUN takes the S and the trade its `I` line — and in this batch the run's own shelf almost always
#     exists in an earlier batch, so the merge is declared (18 merge-with lines to landed partners).
# (2) READ-ORDER / chronology folders (`_X-Men Complete Chronology V2`, `_Marvel Cosmic\01 Prelude`,
#     `Guardians of the Galaxy\Misc`, `Death's Head (FPA)`): one file = ONE ISSUE of a long run, split into
#     its own shelf by the story title in the filename. Every such shelf takes the run's ids + merge-with.
# (3) A folder of SEPARATELY TITLED one-shots read as one shelf (I (heart) Marvel, Marvel Romance Redux,
#     Marvel's Avengers, Marvel's Hero Project, Marvel Monograph, Millarworld Annual, the Ultimate Marvel
#     Handbook): each book has its own count-1 record in one or both catalogs and nothing spans the shelf →
#     R + split-needed with the per-book ids in the clause.
# (4) Promo cards, original-art pages, 1pp cover scans and DCP "Archive Edition" compiles → R + not-a-run.
# Spellings that hid a record from the parsed key here: the apostrophe year ("Cable '99" is filed "Cable
# 1999" in BOTH catalogs), the INFINITY issue number (Black September's only issue is numbered "∞", which is
# what the filename's "- Infinity" means), the Wizard co-publication (GCD mints "Wizard Wolverine" and a
# separate Marvel;Wizard "Generation X" for the ½ issues), and Marvel's own renumbering of Ultimate Comics
# Avengers 1/2/3 as ONE 18-issue volume in both catalogs.
