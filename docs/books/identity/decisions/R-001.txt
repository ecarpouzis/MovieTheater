# R-001 — REVISIT of seven all-trade shelves under the sharpened ruling "the RUN wins whenever a numbered run
# exists". Every one of these seven is the same shape: the shelf holds only "COL ... Vol. NN" digital trades
# (Son of Ultron-Empire / Vee-Empire / Shadowcat-Empire), and both providers carry TWO records per title — the
# issue run, and a same-title record whose count equals the NUMBER OF TRADES WE OWN. In six of the seven the
# stored CV link is that second record (the "matches our holdings" lie shape), and GCD's per-file leg is its
# twin, marked [collected edition] in the dump. So the per-file legs are not two independent legs here: they
# are one lie told twice. The run record is found in the CV candidate list / CV local rip / GCD dump instead.
# Three of the seven are not one run at all: the trades collect two or three sibling minis that each number
# from #1 (Snifter of Terror season one + season two; Days Missing + Kestus + Enox; She Could Fly + The Lost
# Pilot + Fight or Flight), which is the co-equal-runs case -> R + split-needed, not an S on the first run.
# Page arithmetic did the deciding throughout: a 121pp trade is five 24pp issues, not one issue.
