# Savage Dragon minis, Universal Monsters, Transformers compendiums), Knights of the Dinner Table strays and side-runs
# (Kenzer), Hans Rickheit / Box Brown zines, Powers 25, and a run of Mad Cave graphic novels.
# Conventions seen: 2026 Image launches are mostly newer than the ComicVine rip, so GCD (to mid-2026) is the only leg and
# its counts trail our ladders (0.9). GCD files each 2025-26 trade as its own count-1 series with the ISBN — that row is
# the trade's I line and the run is the S (run-wins). The Transformers Compendium spans several Marvel runs (GCD reprint
# roll-up) and keeps its own identity with C lines; the G.I. Joe and Kill or Be Killed compendiums reprint ONE run.
# Several Dark Horse / Mad Cave / Marvel books sit in Image\ folders (Jumpscare, Los Monstruos, Gunpowder Prophets,
# Iceman: Omega) — publisher from the records, folder is a filing convenience.
