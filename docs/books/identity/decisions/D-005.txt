# D-005 — tier D (no stored provider leg), 120 shelves: the Drawn & Quarterly per-ARTIST folders, Dynamite's
# art books / one-shots / omnibus tail, two Dark Horse archive lines, Eclipse, the Europe Comics digital
# album programme (Black Moon Chronicles 16 shelves, Lena 3, Thorgal, Undertaker, Route 66) and the whole
# Fantagraphics singleton shelf.
# Three shapes carry the batch. (1) The GCD-only 2018-2024 art-comics singleton: Fantagraphics and D&Q
# publish one book per record and GCD indexes it while the ComicVine rip does not, so `cv=- gcd=<row>` +
# provider-missing is the honest line and the GCD issue's ISBN/page count carries the `I`. (2) The Europe
# Comics shape at full strength — ONE ComicVine volume per album LINE whose issue names are our filenames'
# subtitles, against GCD's FRENCH original (Dargaud / Le Lombard / Soleil): that splits one folder into one
# shelf per album, so Black Moon Chronicles (16), Lena (3) and the Huizenga/Ganges pair are merge chains,
# not comics. (3) Dynamite's count-1 collected record beside every run — the run wins wherever a numbered
# run exists (Gold Key: Alliance, Red Sonja/Conan, Robots vs Princesses, Red Team, Peter Cannon).
# Six shelves are ripper-cut EXTRACTS (2-6pp of an anthology or a book) and take partial-rip; five are
# licensed art/reference books absent from both catalogs.
