# B-065 — tier B, the tail of `Misc\` (Valentine through Zot!, the `_`-prefixed creator folders and the
# Aspen and John Carpenter/Storm King shelves), the whole MonkeyBrain folder, and the first 90 shelves of
# the `Oni Press` folder.
# Conventions of this batch: (1) the Oni Press folder is overwhelmingly ONE 100-300pp collected book per
# shelf, and Oni mints a same-title count-1 record beside every mini in BOTH providers — the stored link
# is that trade record on a dozen shelves here (Alabaster Shadows, Blood Feud, Cemetery Kids, Cult of the
# Lamb, Morning in America, Odd Schnozz, Orphan Blade, Princess Ugg, Terrible Lizard, Meteor Men, Action
# Journalism), so `wrong-cv-link` + the RUN on the S line is the commonest shape in the batch;
# (2) GCD's Oni coverage is patchy in a way ComicVine's is not — roughly a third of these Oni books have
# a CV volume and no GCD row at any spelling, which is an honest `provider-missing`, and where GCD does
# have the book it usually mints TWIN count-1 rows (Ghost Hog 144986/144987, Pilu of the Woods
# 144132/144133), capping those lines at 0.9; (3) Storm King's two programmes (Storm Kids, Tales of
# Science Fiction) file a NEW record per title in both providers, so a shelf holding five or ten different
# titles is several comics with no spanning record; (4) MonkeyBrain's digital-first line is a total GCD
# hole — nine shelves take `gcd=-` and GCD's only rows are the IDW print collections years later;
# (5) Aspen's modern digital runs carry CV volumes with no CvVolume row (needs-fetch) and no GCD leg.
