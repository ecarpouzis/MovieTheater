# A-029 — 136 shelves, all tier A, and almost all of them small-press. The batch runs the tail of the
# alphabetical `Misc\` folder (R through Z plus the _Anne Rice / _Aspen / _Frank Frazetta / _John Carpenter
# buckets), then Monkeybrain, Oni Press, PaperFilms, Papercutz, Red 5, SLG and the first half of Scout
# Comics (and Black Caravan). Two thirds of the shelves are a complete four-to-six-issue mini whose two legs
# agree on publisher, start year and count and whose filenames carry "(of 0N)" — the cleanest shape there is.
# Three folders behave as sub-libraries and are worth naming. Misc\The Tick is a numbered reading-order
# folder (01..07 plus Misc and "Specials and Annuals") where each numbered subfolder is a DIFFERENT New
# England Comics series, not a volume of one; every one of them resolved on its own pair of records.
# Misc\Street Fighter is the same shape for UDON: six one-shots, two minis, a 2005 seven-issue run and the
# Unlimited ongoing all sit in one folder, and only the Annual crosses a run boundary. Scout's folder is a
# long tail of count-1 2021-2024 one-shots where both legs say the same thing and nothing is ambiguous.
# Trade-only shelves behaved exactly as the ledger predicts. Five stored CV links are the TPB/collected
# record while a numbered run exists on both legs: Aspen Universe: Revelations (98802 over the run
# 92169/104179), Love Fights (56925 over 30331/14277), Gods of Brutality (165058 over 137758/178009),
# Killchella (157383 over the run GCD 192587, whose CV volume is not in our data at all) and Long Lost
# (112457, count 2 = exactly the two books we hold, over the two six-issue seasons). Five `F wrong-cv-link`
# from one cause, plus Spectacle where the stored 111056 (count 5) is neither the 22-issue digital run nor
# our four books.
# One refusal: S2413 Behemoth is two different comics that both number from #1 — three 2015 MonkeyBrain
# files and one 2025 Dark Horse file — and the stored link describes only the Dark Horse book.
# Two round2 legs appeared and both were wrong in the familiar way: S22838 (Becky and Bob) was handed its
# folder neighbour Hack/Slash Meets Zombies vs Cheerleaders, and S1816 (Bandette) was handed Dark Horse's
# four-issue print repackaging of a twenty-two-issue MonkeyBrain digital run. Both take `gcd=-`.
# NEW CONVENTIONS for the ledger (details in the N lines): (a) a provider count ABOVE our holdings on a
# series whose end year is "?" is staleness, not a residue — it does not cost the line anything, while a
# count BELOW our ladder or a count-1 stub does; (b) NBM/Papercutz album lines carry TWIN adjacent GCD rows
# for one book line (120209/120210 Hotel Transylvania, 162923/162924 School for Extraterrestrial Girls) that
# the packet cannot separate — take the per-file one at 0.9; (c) Misc\The Tick's numbered folders are
# reading order, not volumes.
# I-line convention as in A-016..A-028: a book gets an I line only when its own record is different from or
# finer than the S line's — so trades beside a run get one, and a shelf whose S line already IS the
# collected/volume series does not.
