# B-006 — 150 tier-B shelves: the tail of BOOM! Studios (The D-Z titles + WWE), then Caliber Comics,
# Cinebook, Clover Press and a 70-shelf block of **ComiXology Originals**, which is the batch's real story.
# The BOOM half behaves exactly as B-004/B-005: run + a same-title count-1 trade record a year later in
# both providers, the stored link on the trade eleven times.
# Conventions this batch adds:
# (a) **ComiXology Originals is a two-provider split, not a missing leg.** ComicVine indexes the DIGITAL
#     serial under the creator's own imprint (Best Jackett Press, Curt Pires, Stout Club, New Wave Comics,
#     4Twenty, Comicraft, Dazzling Urbanite, Migdal, Sablevision, Wimzi...), count 4-6; the GCD dump holds
#     ONLY Dark Horse's later PRINT repackaging, count 1-3, one to three years later. That is the ledger's
#     Best Jackett shape and it is systematic here: 30 of the ~70 CmX shelves pair that way. I have taken
#     the ruling's second option — link the Dark Horse reprint and say so — which caps every one of them at
#     0.9; where GCD has no Dark Horse row at all it is `gcd=-` + provider-missing.
# (b) The CmX per-file CV leg is the count-1 COLLECTED record about a third of the time (Lost on Planet
#     Earth, The Final Girls, Superfreaks, Edgeworld, Barnstormers, Mistland, Goliath Girls, Funny Creek) —
#     the same trade-record trap as BOOM, at a different set of publishers.
# (c) ComicVine mints TWIN volumes for several Stout Club / Shadow Valley CmX series (Funny Creek 129224 +
#     129225, Hailstone 135976 + 135977, Goliath Girls 112399 + 112400) — capped and named.
# (d) Cinebook second legs are found by dropping the English subtitle to the ORIGINAL abbreviation: "HSE"
#     (GCD 179495, Cinebook 2020, 3) is the second leg for the shelf our files call "HSE - Human Stock
#     Exchange". Cinebook's GCD rows carry [en-gb] and the Cinebook publisher — that column is the test.
# (e) Caliber's digital line re-serialises 1990s one-shots under a new numbering (Worlds of H.P. Lovecraft
#     1-10) — GCD holds a row per ORIGINAL one-shot and neither provider has anything spanning ten.
