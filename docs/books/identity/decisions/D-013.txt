# D-013 — tier D, 120 shelves. Almost all of it is the `Manga\` tree plus three tails (Markosia, the
# Marvel-IDW Star Wars reprint/companion folders, a few Marvel promo one-shots). The dominant shapes:
# (1) ONE published line cut into many single-volume shelves by the SUBTITLE in the filename — Path of the
#     Assassin (14 shelves = Dark Horse's 15 volumes), Shigeru Mizuki's Kitaro (6 = D&Q's 7), Showa (4 = 4),
#     the Clone Wars omnibus (3 = 3). Both legs hold the LINE, so every sibling takes the line's ids and the
#     merge is declared.
# (2) The creator folders (`_Hideshi Hino`, `_Junji Ito`, `_Inio Asano`, `_Daisuke Igarashi`, `_Taiyo
#     Matsumoto`) are SCANLATIONS of works neither catalog indexes at all — provider-missing is the normal
#     verdict, and where ComicVine does hold the Japanese original (Yami no Koe, Takemitsuzamurai, Mad Bull
#     34, Ashita no Joe) that original is the honest 0.9 leg.
# (3) The packet's "CV candidates" block is worthless here: it probed the parsed key, so single-word keys
#     ("Flower", "Island", "Horror", "Snow", "Circus", "Legend", "Manga") returned foreign weeklies. Every
#     verdict below is a re-probe of the FILE's own full title.
# Three spellings hid a record from norm_name in this batch: the superscript in "Alien³" (CV 4859 / GCD 4527),
# the periods in "Welcome to the N.H.K." (the catalogs file it "Welcome to the NHK"), and the double h in
# Marvel's "Kahhori". A fourth: the ripper's literal translation of a Japanese title — "Fragment of Evil" is
# 魔の断片, published in English as "Fragments of Horror".
