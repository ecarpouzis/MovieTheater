# A-021 — 126 shelves, all of them Marvel's alphabetical folder from Big Hero 6 to Marvel Zombies Christmas
# Carol, plus the Deathlok/Hercules/Marvel Tales sub-folders. This is the cleanest batch of the five I have
# read: 108 shelves are a single numbered Marvel run with a CV volume and a GCD series agreeing on publisher,
# start year and count, and a ladder that fills or sits inside it.
# The one recurring hazard is round2-folder / round2-series, which went 0 for 7 here and would have been
# actively destructive four times: it gave "Force Works Ashcan Edition" the 22-issue Force Works ongoing,
# "Thor: The Worthy" the neighbouring "Avengers: Loki Unleashed!", and it handed the SAME record — GCD 144637
# "Marvel Tales: Avengers" — to four different Marvel Tales one-shots (Annihilation, Black Panther, Doctor
# Strange, Venom), which would have merged five shelves into one. In every case the GCD *dump* lookup names
# the right per-title series exactly, so the fix is always to read the dump line rather than the per-file leg.
# Second cluster: "(of NN)" loses to the providers twice. All-Winners-style solicitation cuts — Dark Agnes is
# "(of 05)" on both files where CV and GCD both record two issues (a 2020 COVID cancellation). Named, 0.9.
# One wrong-cv-link: S7530's single file is "Giant-Size Marvel Adventures Avengers 001 (2007)" but the stored
# volume is CV 30674 "Giant-Size Marvel" 2005 — a different comic; the right pair is CV 18922 / GCD 25880.
# Foreign files folded onto a shelf, four times, all F misfiled: Yen Press's 2015 Big Hero 6 manga under the
# 2008 Marvel run; three IDW Godzilla books under Marvel's 1977 Godzilla; four 1996 Marvel Fanfare v2 issues
# under the 1982 v1 run; and a Valiant "Destroyer 0" from a Valiant chronology folder under Marvel's 2009 mini.
# Two shelves are one comic that CV groups and GCD splits: Marvel Legacy's three 2006 decade Handbooks are one
# 4-issue ComicVine volume and three separate GCD series, so gcd=- + provider-missing and an I line each.
# Reprint/collected lines (Killraven Epic Collection, Marvel Firsts, Marvel Two-In-One Epic Collection, Marvel
# Zombies Complete Collection) take the collected line at 0.9 with an N naming the run underneath.
# I-line convention as in A-016..A-020: a book gets an I line only when its own record differs from the S
# line's, and no item-level ComicVine issue ids appear in this packet, so every I line is gcd=s<series>.
