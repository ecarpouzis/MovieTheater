# A-003 — 99 shelves, almost all of them small publisher-folder runs: AfterShock (42), Ahoy (14),
# Albatross, Alterna, Alien Books, American Gothic Press and the long American Mythology tail
# (Pink Panther, Stargate, Zorro, the Edgar Rice Burroughs licences).
#
# The folder convention here is a strong one and it held on every shelf: <Publisher>\<Title> (<year>)
# with one file per issue named "<Title> NNN (<year>) (digital) (<ripper>)", so the filenames carry the
# run's own title, its start year and its ladder, and they agreed with the stored CV volume on all but a
# handful. That is what makes tier A cheap: the count ratio 1.00 lines are not an oracle's verdict, they
# are our own filenames agreeing with two independent records.
#
# Four shapes were worth the reading:
#   1. GCD's per-file link is only as good as the METHOD that made it. Every `round2-folder` link in this
#      batch was WRONG — it matched a file to whatever GCD series another file in the same publisher
#      FOLDER had matched. "New Years Prey" and "The Little Stooges" were both handed
#      "Silent Night Deadly Night vs. Valentine Bluffs Massacre"; "Archie Meets Ramones" (next batch) got
#      "Archie vs Sharknado". Where the dump carried the right series I named it; where it did not, gcd=-.
#   2. The 2018 "Fear on Four Worlds" crossover is four separate one-shots (Carson of Venus, Moon Maid,
#      Pellucidar, Land That Time Forgot). GCD records each as "Edgar Rice Burroughs' <title>: Fear on
#      Four Worlds"; the per-file links had all three of ours pointing at one 2019 "Pellucidar" record.
#   3. A trade on its own shelf: the shelf is still the RUN when the two legs' run records agree; the
#      collected-edition record is the identity only where both legs carry one AND its issue count equals
#      the number of volumes we hold (S15562, S6011).
#   4. Two shelves are two runs sharing a #1 and got F split-needed + R rather than an S.
#
# WEB: 0 fetches. comics.org, comicvine.gamespot.com and leagueofcomicgeeks.com all answer WebFetch with
# HTTP 403, so nothing on this batch rests on a web citation; the two shelves that wanted one
# (S19361, S18921) are decided on the local rip + dump and carry the doubt in their clause.
