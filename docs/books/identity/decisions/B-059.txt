# B-059 — Marvel's Spider-Man family (Spider-Girl, Spider-Ham, Spider-Punk, Amazing/Spectacular/Sensational
# Spider-Man trades and one-shots, Spider-Woman, Squadron Supreme, Squirrel Girl, Thanos). 150 shelves, and
# ~110 of them are ONE book. Two folder shapes decide nearly the whole batch, and they point opposite ways:
#   * a file sitting directly in a BUCKET (`00 TPBs`, `__OGNs, Minis & One-shots`, `_Trades, minis and
#     one-shots`, `Original Graphic Novels`, `00 Annuals and Specials`, `__Omnibus Editions`) names no run —
#     the BOOK's own count-1 record, which Marvel-era shelves get minted in BOTH providers, is the identity;
#   * a `<Title> [vN] (<year>)` per-title folder holding only a collected edition is the RUN's folder — the
#     run takes the S line and the trade takes an I line. That is where every `wrong-cv-link` here comes from:
#     the stored link is the count-1 trade record on 19 of these shelves, exactly the IDW/BOOM/Image shape.
# I overrode "the run wins" only where the arithmetic refuses it (a 201pp digest is not a 4-issue mini, a
# 551pp vertical rip is not a 4-issue print mini) or where the run already owns another shelf (Thanos 2003).
# Surprises: GCD hides "Spider-Man vs. Black Cat" as "Spider-Man vs. The Black Cat" (40812) — the packet's
# probe missed it by one article; and the Epic Collection shape is total here (CV a volume per BOOK, GCD one
# line row: 74602 for ASM, 210504 for Spider-Girl Modern Era).
