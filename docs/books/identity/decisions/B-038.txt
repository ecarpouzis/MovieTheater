# B-038 — 150 tier-B shelves: the tail of IDW's Star Trek and alphabet folders, then Icon, then Image
# from '68 to Bingo Love. Same IDW trade trap as B-037 and at the same rate — 39 `wrong-cv-link` lines,
# every one a same-title COUNT-1 record minted a year after a mini while the run sits one line below it
# in "CV candidates" with a matching count-N row in the GCD dump.
#
# Findings worth the ledger:
#  (1) **A second 1.0 from a barcode.** S19751's file carries an EAN13 read off the page, 9781631404894,
#      and GCD issue 2768685 — issue #[1] of series 117236 "The Obscure Cities" (IDW 2016, 128pp), titled
#      "Theory of the Grain of Sand" — prints exactly that ISBN. That probe also produced a **new instance
#      of the Cinebook shape inside IDW**: GCD keeps ONE series for IDW's seven-album Obscure Cities line
#      while ComicVine mints a volume per album (96106 for this one).
#  (2) **A GCD series can span a shelf ComicVine splits by YEAR.** The X-Files X-Mas Special is one GCD
#      series 85395 with issues #2014, #2015, #2016 (52pp each), while ComicVine has three count-1 volumes
#      (79032, 86799, 97086). Per the ledger's Earth-Prime rule the provider that spans the shelf carries
#      the S line; ComicVine takes `provider-missing`. GCD 98146 does the same for the two X-Files
#      Deviations one-shots, and 77394 did it for My Little Pony's annuals in B-037.
#  (3) **Five reprint/edition shelves where the ORIGINAL wins** (the EC-Archives ruling, applied where
#      BOTH legs hold the original as a discrete series): The Last One (Vertigo 1993, CV 4969 / GCD 4650),
#      Zero Girl (Vertigo 2000, CV 18563 / GCD 24057), Bang!Tango (Vertigo 2009, CV 25733 / GCD 33888),
#      100% (Vertigo 2002, CV 19316 / GCD 17577) and Voyage to the Deep (Dell 1962, CV 2074 / GCD 1512).
#      Each keeps the modern printing on its `I` line. A FACSIMILE of a single issue is NOT this shape —
#      Star Trek's three facsimile editions keep their own records, with an `N` naming what they reproduce.
#  (4) **Four shelves are several comics** and take `R` + `split-needed`: The Cape (the 2011 mini's trade
#      and the 2012 sequel's trade), Astro City (three 2004 one-shots, a 2022 special and a Metrobook),
#      plus the two-run shape on The Mirror War (capped at 0.9, not split, because one run dominates).
#  (5) **Reprint-library lines carrying their own S at 0.9 with an `N`**: Star Trek Archives (5 volumes,
#      GCD page counts within 2-7pp of our rips), Astro City Metrobook, Battle Chasers Anthology (its run
#      is split Image #1-4 / DC #5-9 / Image, so no single run record) and Battlepug: The Compugdium.
#  (6) The GCD dump is blind to a cluster of one-book IDW/Image titles — A Land Called Tarot, Batula,
#      Adrift (Image 2015), Sam Kieth's Maxx Artist's Edition, The Man from the Great North, Star Trek's
#      Scheimer Barrier, Best of Captain Picard, Captain's Log and TNG: Hive — nine honest
#      `provider-missing` flags, every one confirmed by a direct probe rather than assumed.
