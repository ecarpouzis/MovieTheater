# R-025 — a REVISIT of seven shelves: four that an item-pass reader found holding a MISFILED book
# (S6071, S2510, S15139, S924), two chain-of-minis shelves handed the FIRST mini's record (S3644, S5031),
# and one refusal to flip (S96188). Each shelf is decided on what it holds TODAY: a single misfiled book is
# residue (S at 0.9 + F misfiled + that book's own I and C lines), while two or more whole books of a
# different run with their own record are a co-equal run (R + split-needed) unless a provider holds a
# collected LINE record coextensive with the shelf on any leg.

# the 2014 "Elektra: Bloodlines" trade (series 88752, 116pp) — the book we hold is the 2012 "Elektra by Greg
# Rucka Ultimate Collection", CV 46613 / GCD 152146, 388pp, ISBN 978-0-7851-6393-0, and GCD's reprint rows
# say exactly which issues it holds. A-025 read item 88759 as Elektra (2001) #15; the filename says "v1" and
# GCD's story record for the 1996 series' #15 ("The Dark Castle": Amiko, Yukio, Silver Samurai, the Hand) is
# why an X-Men chronology folder holds it, while 2001 #15 is "Introspect Part 5" with no X-cast. C-030's
# Criminal I lines cited the MARVEL first-edition trades; our seven books are the IMAGE 2015-16 printings,
# and both legs index that printing line volume-for-volume.

# (the C lines below on Elektra, Casanova and Criminal come from it), and gcd_series.notes spells out the
