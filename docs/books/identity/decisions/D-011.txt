# D-011 - tier D (no stored provider leg), 120 shelves in three unrelated blocks:
#   (A) the tail of `Heavy Metal\Heavy Metal Magazine (1977)` - 21 more `_Back Issues\YYYY` per-issue
#       shelves (2004-2011), 12 more `special` shelves (2004-2008), the `metal-hurlant` folder and four
#       loose Heavy Metal / Titan books. Read exactly as D-010: CV 19498 / GCD 110631 for the monthly
#       (merge into S8533), CV 35025 "Heavy Metal Special" / GCD 77284 for the seasonal companion
#       (merge into S8537, the anchor D-010 set). The filename's VVxNN is ComicVine's issue NAME.
#   (B) Humanoids' English programme - one book, one count-1 record per leg, and 2022-2023 Life Drawn
#       titles that are past the ComicVine rip's horizon (GCD-only) or past BOTH (R).
#   (C) IDW and Image - the count-1-trade-as-stored-link population this ledger already knows, read the
#       usual way: the numbered RUN takes the S, the trade takes the `I`.
# What this batch taught, in order of how much work it saved:
#   1. `SELECT * FROM gcd_series WHERE publisher_id=<n>` and a LIKE on `cv_vol.name` beat every normalised
#      probe on a tier-D shelf, because the shelf key is a truncation. `lookup.py "Corazas"` returns
#      nothing; `LIKE '%Best of Teenage%'` found the whole "Best of Teenage Mutant Ninja Turtles
#      Collection" line (CV 157473 / GCD 186233) that "Best of TMNT Collection" cannot reach.
#   2. Two ripper spellings that hide a record from the normaliser: the SLASHED O ("Gødland Finale" CV
#      69879) and a SPACE inside the word ("How Toons: Tools of Mass Construction" CV 75884).
#   3. Titan's Druillet Library and IDW's Godzilla Rivals one-shots are the Silver Sprocket shape at its
#      purest - one record per BOOK in BOTH catalogs and no spanning row anywhere - so a shelf holding
#      several of them is R + split-needed, not a comic.
#   4. The barcode lane paid again: four EAN-13s on the Obscure Cities shelf resolved to `gcd_issue.isbn`
#      outright, and one of them (9781628472271) proved the book is Alaxis Press's 2014 printing and not
#      the IDW line's own volume - a 1.0 that also corrects which SERIES the book belongs to.
