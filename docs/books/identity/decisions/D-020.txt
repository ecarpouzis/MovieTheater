# satellite shelves, two Authority specials, the Devil's Night 2000 annuals, Herogasm, Warcraft); Zenescope;
# and a dozen `_Marvel Major Event Chronology (digital)` tie-in shelves.
#
# The batch's best finding is a BARCODE one. Four Wildstorm shelves carry EAN-13s read off the page, and on
# every one the 11-digit UPC core is shared by the whole GCD series, which identifies the series outright:
# 0709853046035 → GCD 5650 "Gen 13 Bootleg" (the core 70985304603 appears on 19 of its 20 issue rows);
# 0761941233482 → GCD 10346 "Gen 13" 2002-2004 (the core 76194123348 on all 17 rows #0-16, exactly our
# ladder); 0709853045717 → GCD 27172 "Gen 13: Magical Drama Queen Roxy" issue #2; and three separate
# Herogasm barcodes resolve to GCD 37153's issues #3, #4 and #6 one for one. That is the cheapest 1.0 in the
# tier and it needed no name probe at all — which matters here because the packet's CANDIDATE blocks for the
# Gen13 folder were catastrophic: every one of them offered Warren's "1994" (the parsed key's YEAR read as a
# title), "Gen13: Meanwhile" and "Wildstorm Fine Arts", and not one reached the run.
#
# CONVENTION LEARNED (for the ledger): both catalogs write Gen13 with a SPACE — "Gen 13" — so every probe
# and every candidate block built on the folder's "Gen13" misses the entire franchise. B-0xx already logged
# the space trap for "Gen13: Armageddon" and "Superman/Gen 13"; it is not a one-off, it is total. It also
# hides a COLON: ComicVine files the 1997 mini as "Gen 13: Interactive" (27445), which a LIKE on
# "Gen 13 Interactive" cannot see while GCD writes it without one (72061).
# CONVENTION LEARNED: a second rip of a book an earlier batch already landed shows up in tier D as a
# stored-CvVolumeId collision, and the right move is to copy the landed sibling's ids verbatim rather than
# re-derive them — five shelves here (S18040→S1516, S5284→S15342, S18034→S18027, S20971→S20967,
# S20960→S8068) are duplicate rips whose partners were decided in earlier batches with exactly the ids the
# evidence gives again.
# CONVENTION LEARNED: Zenescope one-shots carry SIX or SEVEN GCD rows that are all variant covers of one
# issue (`variant_of_id` points at the base), so the base row — the only one with a page count — is the `I`
# line's id and the row count is not a series count.
#
# SYSTEMIC FINDING for the lead: S20960 is a second rip of the book S8068 landed on the count-1 collected
# record CV 76459 / GCD 209919. The run behind that book is the four-issue "Grimm Fairy Tales presents
# Helsing" (CV 73254 / GCD 80321, 2014), and the run-wins rule would put the run on both shelves' S lines
# and 76459/209919 on their `I` lines. I have copied the landed sibling's answer so the two rips of one book
# do not get two identities, and I am presenting the conflict rather than silently re-deciding S8068.
