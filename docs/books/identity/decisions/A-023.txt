# bucket) through _Ghost Rider: Black Panther, Black Widow, Blade, Captain America, Captain Marvel, Carnage,
# Cloak and Dagger, Conan, Daredevil, Deadpool, Defenders, Doctor Strange, Dr. Doom, Elektra, Eternals,
# Fantastic Four. Two thirds of the batch is the house shape — a Marvel mini in its own `<Title> (YYYY)` folder,
# every filename carrying "(of NN)", a CV volume and a GCD [limited series] agreeing on publisher, year and
# count. Those are 0.95 and unremarkable.
# What the batch is really about is the collected-edition shelves, and they split cleanly in two:
#  (a) EPIC COLLECTION / VISIONARIES / OMNIBUS lines whose books reprint several different runs (Captain
#      America Epic Collection, Conan Chronicles Epic Collection, Defenders/Deadpool/Doctor Strange/Fantastic
#      Four Epic Collections, FF Visionaries: John Byrne, Daredevil Visionaries, the three omnibus shelves).
#      No single run record exists, so the collected line IS the identity at 0.9 with an N naming what it
#      reprints. ComicVine mints a VOLUME PER BOOK on these lines while GCD keeps one series for the whole
#      line — which is why five Conan shelves and three Captain America shelves share a GCD id and get
#      F merge-with: they are volumes of one line that the shelf cut split apart.
#  (b) Trade shelves of a run that DOES exist. Six of them, and in five the stored CV link is the collected
#      record whose count equals the BOOKS we hold, exactly as the ledger predicts for Marvel trade-only
#      shelves: Daredevil: Back In Black (CV 90404, count 8 = our 8 books, against a 46-issue run), King
#      Deadpool (CV 130996, count 1), Doctor Strange by Mark Waid (CV 115727, count 1), Doctor Strange by Jed
#      Mackay (CV 153916, count 3), Savage Sword of Conan: The Cult of Koga Thun (CV 120321, count 1). All
#      five F wrong-cv-link, the S line takes the run, the book takes an I line on the collected series.
#      Back In Black is the prettiest arithmetic in the batch: the judged ranges #1-5 + #6-9 + #10-14 + #15-20
#      + #21-28 and then legacy #595-600 + #601-605 + #606-612 sum to 28 + 18 = 46, the exact count both
#      CV 86343 and GCD 94624 record for Daredevil (2016).
# A sixth is a different lie: S64504's stored link is CV 153465, Daredevil (2023, 25 issues), on a shelf whose
# single book is "Daredevil by Chip Zdarsky Omnibus Book 01" with a judged #1-30 — 30 does not fit in 25, and
# Zdarsky's run is the 2019 volume (CV 116964 / GCD 139716, 36). The per-file GCD leg there is Panini France's
# French Daredevil, the foreign-language cluster again.
# `round2-folder` keeps its record: wrong in all seven it touched here (Blood Truce given The Legend's series;
# Deadpool: The Variant Covers given Deadpool: The End's; Eternals: Never Die given Eternals: Secrets From the
# Marvel Universe's; Games of Death given the 65-issue Deadpool ongoing; the three Epic Collection folders
# given their neighbour's line — right line, wrong reason). Twice the DUMP named the right per-title row and
# rescued the shelf (Blood Truce 12779, Games of Death 35315); twice it did not and the shelf takes gcd=- with
# F provider-missing. `round2-series` was right twice this batch (Jungle Action 2053, Cloak and Dagger 3656,
# Sorcerer Supreme 3645) but only because the name, publisher and span check out independently — never on
# the method.
# Variant-cover packs are the whole of every odd ratio on the modern Marvel shelves and cost nothing: S2807 is
# FOURTEEN 1pp files and not one interior page, S1608 is four 1pp covers plus the run's own trade, S6339 is two.
# Two shelves are digital-vs-print: Captain America: First Vengeance is eight 13pp digital chapters (CV 55709,
# Marvel Digital Comics Unlimited) where GCD indexes only the four-issue print mini — gcd=- + provider-missing.
# NEW, and it changes the confidence vocabulary on a whole ripper: a **Marika-Empire rip's ComicInfo `Web` id
# is a ComicVine ISSUE id**, and its volume is the volume the shelf should carry. Checked on 21 of them across
# A-023 and A-024 — every one resolves in the ComicVine reference, and every one's volId equals the CV volume
# the packet's stored link names (175086 -> 28441 Panther's Prey, 259595 -> 38706 Collector's Preview,

# 1.0: the collection asserts the record and a leg agrees. Six shelves here take it. This is the OPPOSITE of
# the ledger's Glorith finding — Glorith Web ids are not GCD issue ids; Marika Web ids ARE ComicVine issue ids.
