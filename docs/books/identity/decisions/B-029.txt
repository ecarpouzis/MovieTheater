# B-029 — the tail of `FirstSecond` (the imprint's own shelves plus its _Box Brown / _Emily Carroll /
# _Faith Erin Hicks / _Gene Luen Yang / _Vera Brosgol creator folders), a 7-shelf `Gold Key-Dell-Whitman`
# block, and the first ~80 shelves of the big alphabetical `Graphic Novels` bucket folder. Almost every
# shelf is ONE BOOK: the default line is ComicVine's count-1 volume and GCD's count-1 series agreeing on
# name, publisher and year, 0.95, with the book's own `I` line carrying both item-level ids (and the ISBN
# where GCD prints one).
#
# Findings worth the ledger:
#  (1) **First Second is a TWIN-ROW publisher in GCD** — 16 shelves here carry two adjacent GCD series for
#      one book (Laura Dean 144668/144669, On a Sunbeam 130899/130900, Snapdragon 155381/155382, Stargazing
#      150792/150793, The Phantom Twin 156586/156588, The Well 185747/185748, This One Summer 82801/94651,
#      This Was Our Pact 146194/146195, One Year at Ellsmere 162930/162931, Pumpkinheads 149909/149910,
#      Anya's Ghost 60457/60644, Be Prepared 123814/123816, American Born Chinese 25828/177618, Ride On
#      188911/188912, A for Anonymous 158279/158285, Zita 59210/122042). They are NOT the NBM twin-row
#      ambiguity: each pair is the HARDCOVER and the PAPERBACK printing, with different ISBNs and page
#      counts, so the PAGE COUNT of our rip picks the row (Laura Dean 302pp -> 144669's 312pp; On a Sunbeam
#      546pp -> 130899's 544pp; Stargazing 224pp -> 150792's 228pp; Pumpkinheads 207pp -> 149909's 232pp;
#      Anya's Ghost 225pp -> 60644's 228pp). Where BOTH rows are blank (Phantom Twin, The Well, Ellsmere,
#      Ride On, A for Anonymous) I cap at 0.9 and name both.
#  (2) **The bucket folder `Graphic Novels` gives every shelf the SAME six candidates** — "The Discworld
#      Graphic Novels", "Dr. Seuss Graphic Novels", "Graphic Novels" (Süddeutsche Zeitung), "Disney Graphic
#      Novels" — because the v1 name search ran on the FOLDER name, not the book's. They are noise on ~70
#      packets here and were rejected on sight everywhere.
#  (3) **Seven RUN-wins on trade-only shelves**, each with the stored/per-file link pointing at the count-1
#      trade record a year later: Box Office Poison (CV 6827 / GCD 7344, the 21-issue Antarctic run, not
#      Top Shelf's 2001 collection), Breakfast After Noon (6540 / 7035), Brooklyn Dreams (5240 / 4950, the
#      four Paradox Press books, not IDW's 2011 omnibus), Cloudia & Rex (102580 / 115266), Bug Bites
#      (129871 / 163722), Atlantis Wasn't Built For Tourists (129638 / 163416), American Terrorist (CV
#      55726, the 7-issue A Wave Blue World run) and All Hallows' Eve (CV 77618, 215 Ink's six issues).
#  (4) **Three wrong stored links that are a different comic entirely**: Ride On (S14679, a First Second
#      2022 GN linked to Kodansha's 2023 manga "Ride On!"), Jetsons (S9834, a 1968 Gold Key issue linked to
#      Archie's 1995 series), Huckleberry Hound (S9065, linked to Federal's Australian reprint), plus
#      Match Point (S11847, a 2023 First Second 259pp GN linked to a self-published 2018 two-issue comic —
#      refused, neither provider indexes the book).
#  (5) **cv=28940 (Gold Key's Looney Tunes 1975) is the stored link of S10928**, a 286-file DC-1994 Looney
#      Tunes shelf that is not in this batch — the volume belongs to S102399, the 45-file Gold Key run. See
#      the F/N pair below.
#  (6) GCD is systematically absent for small-press American OGNs and for Oni's "Quick & Easy Guide" line:
#      24 shelves take `gcd=-` + `provider-missing` at 0.9.
