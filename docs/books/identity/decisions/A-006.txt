# The Boom half reads exactly like A-005 and I applied the same reading: where three trades' judged ranges
# tile a run (#1-4 + #5-8 + #9-12 = 12) and both legs hold a run record with that count, the shelf IS the
# run, and where the stored CV link is instead the collected-edition record whose count equals the number
# of BOOKS we hold, I put the run's id on the S line and wrote F wrong-cv-link. That happened five more
# times here (17021 Suicide Risk, 18541 Expanse: Dragon Tooth, 4777 Danger Street, 18799 The Human Target,
# 15774 Sleepy Hollow) — the TPB-record-as-shelf-link is now the batch-over-batch pattern of this pass.
#
# CINEBOOK is a new house shape and a very clean one: `<Title> NNN - <Album Subtitle> (YYYY) (Cinebook)`,
# one album per file, 50pp each, ComicInfo Publisher "Cinebook", and a GCD Cinebook series whose span is
# the years on our files. On the nineteen Cinebook shelves CV and GCD agree outright on all but three.
# The three exceptions are worth the ledger: Cinebook titles are English editions of French albums, so
# both providers are full of Dargaud / Splitter / Epsilon / Panini rows of the same name, and the per-file
# GCD leg reached for one of them twice — 13470 Outlaws got Splitter Verlag (the dump holds Cinebook's own
# row, 205041) and 20876 Valerian got Cobolt Förlag, a Swedish publisher. On a Cinebook shelf the publisher
# column is the whole test.
#
# 20876 Valerian is the one shelf where NEITHER stored id was right: the seven books are Cinebook's
# "Valerian: The Complete Collection" omnibus, which GCD holds as 115736 (Cinebook, 2017-2018, 7 volumes —
# our seven books and their years exactly) and ComicVine does not hold at all. Its stored CV link is Europe
# Comics' nine-volume digital "Valerian and Laureline", a different edition from a different publisher.
#
# DC BLACK LABEL brought a residue I had not seen before: 1pp VARIANT-COVER files. Four shelves (2101
# Batman: Full Moon, 9818 Jenny Sparks, 9929 Dead in America, 13899 Plastic Man No More!) carry a second
# file per issue that is a single page — the cover — from (MikeNY76-Empire). They are what makes those
# ratios 1.57-2.00 and every number name two files; they are not issues and they do not make two runs.
#
# TWO SHELVES ARE TWO RUNS EACH: 18520 The Empty Man (the 2014 six-issue mini's collection plus two trades
# of the 2018 eight-issue series, and its own ComicInfo says Volume 2018 on those two) and 20724 Uncle
# Grandpa (four unrelated one-shots and OGNs in one folder, no run at all). Both got R + split-needed with
