# A-002 — 94 tier-A shelves: Ablaze (3), Abstract Studio (8, incl. one misfiled Dark Horse shelf),
# Action Lab (23), Aftershock (60).
#
# Aftershock is the most mechanical publisher in the collection: one folder per title, "<Title> NNN
# (YYYY) (digital) (<ripper>-Empire).cbr", almost always a five-issue miniseries, a CV volume and a
# GCD "limited series" that agree on publisher, year and count, and a LOCG bridge whose support
# equals our file count. Fifty-plus shelves here are that shape and nothing else.
# Two Aftershock/Action Lab conventions matter for reading: (a) a SECOND provider record of the same
# title, one year later with a count of 1, is always the collected edition, never a second run —
# every "Betrothed 2019 AfterShock 1" beside "Betrothed 2018 AfterShock 5" is a trade; (b) a sequel
# run lives in a "v2 - <Subtitle>" subfolder under the same title folder, and when the parser folds
# that subfolder onto the parent shelf you get two runs both numbering from #1.
#
# THAT (b) case is the whole of this batch's difficulty and produced the three refusals: Spencer &
# Locke (2017) + Spencer & Locke 2 (2019), Chicken Devil (2021) + Chicken Devils (2022), Jimmy's
# Bastards (2017) + Jimmy's Little Bastards (2022). Each shelf carries a parsed key for BOTH runs,
# so an S line would link the sequel's key to the first run's volume — PLAN §6.9 exactly.
#
# TRADE-ONLY SHELVES: I took the shelf's identity to be whatever the stored shelf-level CV volume
# describes and named the GCD series describing the SAME thing. Where the per-file GCD link is a
# "collected edition" series while the CV volume is the floppy run (Motor Girl, Serial, SiP XXV) I
# took the run's GCD row from the dump and said so; where BOTH legs describe the collected series
# (ECHO, Athena Voltaire and the Volcano Goddess) I kept them.
#
# WEB: 0 fetches. comics.org, comicvine.gamespot.com and leagueofcomicgeeks.com all return HTTP 403
# to WebFetch (verified on four URLs across the three hosts while reading A-001), so nothing here
# rests on the web.
