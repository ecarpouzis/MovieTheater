# A-014 — 120 shelves: almost all of Dynamite (Captain Action Cat -> Z Nation, with the whole Red Sonja and
# Vampirella wings), then Dark Horse's EC/Warren archive line, Eagle, Eclipse and Epic. The house shape here is
# a 4-6 issue Dynamite mini whose CV volume and GCD series agree on publisher, year and count with the ladder
# complete — those are the 0.95 lines and there are ~70 of them.
# Same I-line convention as A-011/A-013: a book gets an I line only when its OWN record differs from what the S
# line carries, and since no item-level ComicVine issue ids appear anywhere in this packet every I line is
# gcd=s<series>. Where a trade's own record exists only as a ComicVine VOLUME (no issue id) and GCD names no
# collected series, the gap is recorded on an N line instead — that is most of Dynamite's trade-only shelves.
# What surprised me: Dynamite's collected-edition records are almost mechanical. For nearly every run there is a
# second same-title record one year later with count 1, and on a trade-only shelf the STORED link is that record
# about a third of the time. 24 shelves here are a single COL file whose stored CV is the run (right) or the
# one-issue trade record (wrong) — the tell is count 1 against a 4-12 issue GCD series of the same name.
# Second surprise: the Red Sonja folder's own conventions. "_Trades, minis and one-shots" and "_Completed
# Series" are bucket folders, and "Red Sonja One Shots" (S14480) is a bucket of nine separate one-shots plus
# four annuals plus two trades from three different runs — no single run, so it is an R.
