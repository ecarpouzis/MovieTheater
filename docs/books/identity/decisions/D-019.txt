# D-019 — tier D, 120 shelves, all of them inside `Webcomics and Strips\`: the newspaper-strip and
# webcomic wing of the library. Three shapes account for 118 of the 120.
#
# (1) A LINE both catalogs index as one series, cut into one shelf per BOOK by the ripper's subtitle.
#     Four of them here: the Ballantine Garfield paperbacks (CV 39429 / GCD 70018 — D-018's finding,
#     seven more books of it land here on S7193), The Order of the Stick (CV 86843 / GCD 92548, the
#     issue NUMBER is the book's place in the line and the issue NAME is our filename), Hermes Press's
#     The Phantom: The Complete Newspaper Dailies (CV 44892 / GCD 50260, whose per-volume page counts
#     match our rips within 8pp volume for volume), and Stand Still Stay Silent's Hiveworks books.
#     In each the survivor takes the S and the siblings take `F merge-with`.
#
# (2) A ONE-BOOK shelf whose book has its own count-1 record. The whole Heathcliff folder is this: GCD
#     indexes each Windmill/Tempo/Charter/Jove paperback as its own series and ComicVine indexes almost
#     none of them. The reading that made it work is the ISBN PREFIX: every "Charter", "Jove" and "Ace"
#     file carries an 0-441 ISBN and GCD files all three imprints under publisher "Berkley Books", and
#     every "Tempo" file carries an 0-448 ISBN, which is Grosset & Dunlap — Tempo was their paperback
#     line. So a file that says "(Charter 1984)" against a GCD row that says "Berkley Books 1984" is the
#     same object, not a mismatch, and the disagreement the packet shows is an imprint, never a comic.
#     GCD also mints a TWIN for most of these (a Tempo first printing plus a Berkley reissue a year
#     later: Strikes Again! 210536/210537, Triple Threat 59665/210530, Rides Again 85083/176815) — the
#     FILE's stated publisher and year pick the row, and the twin is named.
#
# (3) A YEAR-BY-YEAR (or date-range) STRIP ARCHIVE, which is provider-missing however famous the strip.
#     29 Peanuts.YYYY files, 29 Family Circus years, 25 Ziggy years, 11 Zippy the Pinhead years, 7
#     Office Hours years, 5 Olive & Popeye, 3 Legalization Nation, 3 Monologuist volumes, 2 Popeye's
#     Cartoon Club, 2 Bloom County 2015 date ranges and one Outland date range: 63 shelves. The
#     catalogs index the strip's BOOKS, and in several cases hold them plainly (The Complete Peanuts
#     CV 20938 / GCD 15711, 26 volumes of TWO years each; IDW's Bloom County CV 94388 / GCD 110459) —
#     those are different objects from a rip of one calendar year at one page per day, and the page
#     counts say so outright: the Peanuts.1954+ files run 322-366pp, i.e. one image per daily strip.
#     D-018 ruled this shape for Achewood and FoxTrot; it is applied unchanged.
#
# Fourth, smaller finding: 22 of the Peanuts shelves are Simon Spotlight / Ballantine KIDS' TIE-IN
# picture books (10-37pp: "It's Springtime, Snoopy!", "Here Comes the Easter Beagle!", "Hug a Tree,
# Snoopy!") and not one of the 22 titles returns a single hit in either catalog under any spelling —
# a total hole in both, exactly as the licensed-non-comics rule says. The one exception is DK's
# reference book "The Peanuts Book: A Visual History" (S19338), which BOTH legs carry.
#
# CONVENTION LEARNED (for the ledger): the GCD PUBLISHER column on a 1970s-80s paperback strip
# collection is the parent house, not the imprint on the cover — Charter / Jove / Ace all file under
# "Berkley Books" (ISBN 0-441) and Tempo files under "Grosset and Dunlap" (ISBN 0-448). Reject nothing
# on that column alone; read the ISBN prefix.
# CONVENTION LEARNED: a webcomic's own volume divisions need not map onto its printed books at all
# (Stand Still Stay Silent: our 5 webrip volumes of Adventure 1 against Hiveworks' 4 books at
# 336/268/314/228pp) — pair the shelf with the published edition at 0.9 as a format split and write an
# `N` instead of forcing per-book `I` lines onto a mapping that does not exist.
