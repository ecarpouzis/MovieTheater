# A-007 — 98 shelves (88 tier A, 10 tier C): the last of DC Black Label (5), DC Ink (1), and then a long
# run of the DC event folders — the Green Lantern Corps reading order (28), the post-Crisis event order
# (17), the New 52 / Futures End (4), Flashpoint's seventeen tie-ins, and Convergence's twenty-two.
#
# This batch has a shape all its own and it is the reading-order folder. The owner keeps DC's events as
# numbered READING ORDERS — "000 Major DC Events - As seen from Oa - Green Lantern Corps\091 Day of
# Judgement" — so a file's leading number is its position in that reading order, not its issue number, and
# the same book is filed a second time under its own series folder. Two consequences run through the whole
# batch:
#
#  1. TEN SHELVES ARE THE SAME RUN TWICE. Every tier-C flag here (5999 Eclipso, 18575 The Final Night,
#     7359 Genesis, 5001 Day of Judgment, 7924 GL Rebirth, 14387 Rann-Thanagar War, 21084 Villains United,
#     4594 Donna Troy, 4261 Countdown Arena, 4265 Lord Havok, 4275 Countdown to Adventure, 4276 Countdown
#     to Mystery, 14988 Salvation Run, 6675 FCA: Run!) is exactly ratio 2.00 with EVERY number doubled —
#     one copy in the reading-order folder, one under the title's own folder. That is not two runs and not
#     a conflated shelf: the arithmetic is n issues x 2 files, and both legs count n. I said so on each.
#  2. THE ⚠ round2 LINKS ARE ALL THE PARENT EVENT. A file in "091 Day of Judgement" gets the Day of
#     Judgment series; a file in "097 2011 - Flashpoint" gets Flashpoint. Six shelves were mislinked that
#     way and in every one the dump holds the right row: 5000 (Secret Files -> 7102), 7956 (GL/Firestorm ->
#     16147), 22071 (Worlds' Finest: Futures End -> 82717), 6799 and 6801 (the two Flashpoint tie-ins GCD
#     spells with an AMPERSAND — "Deathstroke & the Curse of the Ravager" 59186 and "Frankenstein & the
#     Creatures of the Unknown" 59188 — which is the only reason the name match failed), 5001/18575/4594.
#     The ampersand-vs-"and" spelling split is worth the ledger: it is why two of seventeen Flashpoint
#     tie-ins looked provider-missing when both providers hold them.
#
# The 39 Flashpoint and Convergence tie-ins are the easiest reading in the batch and I did not shorten
# them: each is its own two- or three-issue volume, each file says "(of 02)" or "(of 3)" in its own name,
# and CV and GCD each hold one record of that exact title with that exact count. Their danger is the
# reverse of the usual one — the parent event's volume is one folder away and would swallow all of them.
#
# 23542 is the batch's one wrong-publisher-record link: three DC Ink young-adult "House of El" books whose
# stored CV volume is "Superman: The Unity Saga: The House of El", Bendis's Superman collection. GCD's
# 168381 (graphic novel series, 2020-2023, 3) is our three books to the year.
#
