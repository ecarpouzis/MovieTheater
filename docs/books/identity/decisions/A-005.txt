# A-005 — 95 tier-A shelves: Black Mask (8), Bongo/Simpsons (5), Boom! Studios + Archaia/KaBOOM/BOOM! Box (82).
#
# Two house shapes dominate and they read very differently.
#
# 1. The Boom floppy shelf: "<Title> NNN (YYYY) (digital) (<ripper>).cbr", often with "(of NN)" in the
#    name. On these the two legs almost always agree outright — CV volume and GCD series with the same
#    publisher, the same start year and the same count, and the "(of NN)" our own files carry says the
#    same number a third time. Those are the 0.95 lines and they are the bulk of the batch.
#
# 2. The Boom TRADE shelf: three to six "COL <Title> Vol. NN" files, 100-165pp each, with judged ranges
#    from the containment pass. Here BOTH legs carry two records of the same name and year: the RUN
#    (12 issues, 25 issues, 30 issues) and the COLLECTED series whose count equals the number of books we
#    hold. The judged ranges are what decides between them: when they tile the run exactly — #1-4 + #5-8 +
#    #9-12 = 12 = both legs' count — the shelf IS the run and I say so (Black Badge, By Night, Coda, Bone
#    Parish, Mech Cadet Yu, Grass Kings, Escape From New York, Beneath the Dark Crystal, Once & Future).
#    The stored shelf link is the run's record about half the time and the TPB record the other half; where
#    it is the TPB record I put the run's id on the S line and wrote F wrong-cv-link (3080, 4006, 9973,
#    9995, 13401). This is the single biggest systematic finding of the batch.
#
# The exception that proves it: Goldie Vance (7762). Four trades of the 12-issue run PLUS a fifth book,
# the 2020 OGN "Larceny in La La Land", which is not in the run at all — so the run's record does not
# describe the shelf and the collected series (GCD 115533, five volumes, 2016-2020) does. When a line's
# trades are joined by an OGN in the same numbered sequence, the collected series covers the shelf and the
# run does not.
#
# THREE SHELVES ARE TWO RUNS EACH and got R + split-needed rather than an identity: Abbott (340) is the
# Abbott 2018 trade plus the Abbott: 1973 trade; Bill and Ted (2554) is the Most Triumphant Return trade
# plus the Go To Hell trade; Faithless (6417) is Faithless Vol. 01 plus Faithless III's trade with Vol. 02
# absent. In each case the stored CV link describes ONE of the two books, and applying it hands the other
# run's trade that identity. All three are named with the records their halves should get.
#
# The ⚠ round2 warning held again: every round2-folder / round2-series GCD link in this batch was wrong.
# 15667 (Moe Szyslak) got Krusty's series copied off its folder neighbour — the dump holds Moe's own row,
# 124568. 1859 (Treehouse of Horror) got Otter Press's Australian reprint. 1054 and 13230 got a neighbour's
# row on the one file that is not part of the run. Not one of them survived a look.
#
# WEB: 0 fetches, per the brief — the three sites are closed. Everything below rests on the packet, the
# ComicVine rip and the GCD dump via lookup.py (used on Abbott 1973, Most Triumphant Return, Faithless III,
# Hellraiser Masterpieces, Treehouse of Horror, Ninja Tales, Cursed Pirate Girl, Goldie Vance, Darkwing
# Duck and Klaus — nine of the ten resolved a real question).
